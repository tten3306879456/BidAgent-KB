# 标书智能体专家系统

> 基于 WorkBuddy 的招投标全流程智能辅助系统，覆盖招标文件解析 → 信息抽取 → 商务段编写 → 技术段设计 → 审核 → 排版输出全流程。

## 项目特点

- **9 个专业智能体**协同工作，模拟真实标书团队分工
- **混合知识库架构**：云端共享法规 + 本地私有数据，数据安全可控
- **三级后端选择**：本地全文检索（零依赖）→ ima云端（共享）→ ChromaDB（高级语义搜索）
- **回退审核机制**：编写→审核→回退，确保输出质量
- **数据投喂模式**：智能体不直接访问本地数据库，用户按需上传 CSV
- **社区共享**：法规/废标模式/标书模板脱敏后开源共享

## 快速开始

### 前置要求

- Python 3.8+
- WorkBuddy 桌面版（用于运行智能体专家）

### 1. 克隆项目

```bash
git clone <repo-url>
cd bid-assistant-system
```

### 2. 一键初始化知识库

```bash
cd 知识库管理
python kb_setup.py
```

> **默认使用本地文件检索后端，零安装零下载，30秒完成初始化。**

脚本会引导你完成：
- 选择知识库后端（默认推荐：本地文件检索）
- 可选安装 PyPDF2（如需检索 PDF 文件）
- 导入 5 个种子知识文件
- 验证搜索功能

### 3. 创建本地知识库目录

```bash
python kb_init.py "D:/KB_manager"
```

### 4. 配置 WorkBuddy 专家

将 `expert_prompts/` 目录下的 9 个专家 Prompt 文件导入 WorkBuddy 专家中心。

### 5. 开始使用

在 WorkBuddy 对话中召唤专家：
> "招标解析专家，请帮我解析这份招标文件"

## 知识库后端选择指南

| 后端 | 适合谁 | 优点 | 缺点 | 安装难度 |
|------|--------|------|------|---------|
| **本地文件检索** (默认) | 所有人 | 零安装零下载零配置 | 关键词匹配(非语义) | ⭐ 无 |
| **ima 云端** | 需共享的团队 | 多端同步、团队共享、公共知识库 | 需ima账号 | ⭐⭐ 低 |
| **混合模式** | 进阶用户 | 公共共享+本地数据 | 配置稍复杂 | ⭐⭐⭐ 中 |
| **ChromaDB** (高级) | 有技术能力的团队 | 语义搜索、完全离线 | 需安装依赖+下载模型 | ⭐⭐⭐⭐ 高 |

切换后端只需修改 `kb_config.json` 中的 `backend.type` 字段。

## 数据安全分级

| Tier | 敏感度 | 存储位置 | 示例 |
|------|--------|---------|------|
| 1 | 纯本地 | 本地CSV | 标书模板、排版规则 |
| 2 | 云端为主 | ima知识库 | 法规、标准、废标模式 |
| 3 | 混合必需 | 云端+本地 | 资质、业绩、人员信息 |
| 4 | 高敏感 | 仅本地 | 技术方案、报价策略 |

> 技术方案知识库为公司核心商业机密，严禁上传云端，通过"用户投喂"模式使用。

## FAQ

**Q: 默认的本地文件检索和 ChromaDB 有什么区别？**
A: 本地文件检索用 Python 内置的正则表达式做关键词匹配，零安装零下载。ChromaDB 用 AI 嵌入模型做语义搜索（搜索"资质不够"能命中"资质等级不达标"），但需要安装依赖和下载模型。建议先从默认后端开始，有需要再升级到 ChromaDB。

**Q: 种子文件是什么？**
A: 5 个 .md 文件包含了标书领域的基础知识，随项目仓库分发。运行 `kb_setup.py` 会自动导入到你的知识库中。

**Q: 技术方案数据可以上传到云端吗？**
A: 不可以。技术方案知识库属于 Tier 4 高敏感数据，通过"用户投喂"模式使用。

**Q: 如何向社区贡献内容？**
A: 详见 [共享知识库贡献指南](共享知识库贡献指南.md)。简单说就是：准备内容 → 脱敏处理 → 提交 PR → 审核合并。

**Q: 不使用 WorkBuddy 能用这个系统吗？**
A: 知识库管理脚本可以独立使用。但 9 个专家智能体需要 WorkBuddy 平台运行。
