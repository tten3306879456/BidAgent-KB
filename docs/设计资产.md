### 适用场景

开源版用户使用共享知识库时，可自主上传文件补充缺失内容。本地知识库由用户自行投喂维护。

### 后续开发引用

如需将此设计稿落为前端代码（HTML/React/Vue），可在 Ardot 编辑器中：
1. 使用 `mcp__ardot__batch_read` 读取节点详情
2. 使用 `mcp__ardot__fetch_variables` 获取设计变量转 CSS 变量
3. 使用 `mcp__ardot__export_nodes` 导出 SVG/PNG 素材
