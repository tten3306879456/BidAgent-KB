## 二、阻塞项（必须修复才能开源）

### 阻塞 1：expert_prompts/ 目录缺失

**问题**：README 中写明"将 `expert_prompts/` 目录下的 9 个专家 Prompt 文件导入 WorkBuddy 专家中心"，但该目录在项目仓库中**不存在**。

9 个专家 Prompt 当前只部署在 WorkBuddy 插件目录：
```
C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins\
├── bid-analysis-expert/         (agents/bid-analysis-expert.md + plugin.json)
├── tender-review-expert/        (agents/tender-review-expert.md + plugin.json)
├── resource-matching-expert/    (agents/resource-matching-expert.md + plugin.json)
├── commercial-bid-expert/       (agents/commercial-bid-expert.md + plugin.json)
├── technical-architect-expert/  (agents/technical-architect-expert.md + plugin.json)
├── technical-bid-writer-expert/ (agents/technical-bid-writer-expert.md + plugin.json)
├── technical-review-expert/     (agents/technical-review-expert.md + plugin.json)
├── bid-review-expert/           (agents/bid-review-expert.md + plugin.json)
└── document-formatting-expert/  (agents/document-formatting-expert.md + plugin.json)
```

**影响**：其他用户 clone 项目后无法获得专家 Prompt，整个标书流程无法运行。

**修复方案**：
1. 在项目根目录创建 `expert_prompts/` 目录
2. 将 9 个专家的 `agents/*.md` 文件复制到 `expert_prompts/` 下
3. 同时复制 `plugin.json` 文件作为导入参考
4. 确认 Prompt 中不含个人敏感信息（当前检查未发现个人名称，但专家有虚构人名如"林之远"，可保留或通用化）

---

### 阻塞 2：个人 KB ID 硬编码（7个文件，10+处）

**问题**：个人 ima 知识库 ID `<YOUR_IMA_KB_ID>` 出现在以下文件中：

| 文件 | 出现位置 | 内容 |
|------|---------|------|
| `guides/知识库使用指南.md` | 第184行、第715行 | "你的知识库" + KB ID |
| `scripts/kb_sync_result.json` | 第17行 | `"kb_id": "<YOUR_IMA_KB_ID>"` |
| `scripts/kb_sync_manager.py` | 第50行、第63行 | 默认值 `"<YOUR_IMA_KB_ID>"` |
| `scripts/kb_init.py` | 第39行 | 默认配置 `"ima_knowledge_base_id": "<YOUR_IMA_KB_ID>"` |
| `docs/标书智能体专家系统设计.md` | 第105-106行 | 知识库部署记录表 |
| `docs/真实招标实例功能测试报告.md` | 第52行 | 测试中引用的 KB ID |
| `docs/真实招标实例功能测试报告.html` | 第129行 | 同上 HTML 版本 |

**影响**：暴露个人 ima 账号信息；其他用户运行脚本时默认使用错误的 KB ID。

**修复方案**：
- 所有硬编码的 KB ID 替换为空字符串 `""` 或占位符 `<YOUR_IMA_KB_ID>`
- `kb_init.py` 和 `kb_sync_manager.py` 中的默认值改为空字符串
- `kb_sync_result.json` 和 `kb_sync_log.json` 重置为初始状态
- 文档中的"你的知识库"改为"你的知识库"

---

### 阻塞 3：kb_config.json 硬编码 Windows 路径

**问题**：
```json
"base_path": "D:\\KB_manager"
```

**影响**：Linux/macOS 用户路径不兼容；Windows 用户路径也可能不同。

**修复方案**：
```json
"base_path": ""  // 留空，由 kb_setup.py 引导用户填写
```
或改为相对路径 `"base_path": "./kb_data"`。

## 七、开源后的用户体验路径

### 最简路径（方案 A，零外部依赖）

```
Clone 项目 → cd scripts → python kb_setup.py → 选择 local_search → 完成
```

用户获得：本地全文检索 5 个种子知识文件 + 9 个专家 Prompt（需 WorkBuddy）。

### 推荐路径（方案 A+B 混合）

```
Clone 项目
→ 注册 ima 账号
→ 创建 ima 知识库
→ 用 upload 脚本上传 seeds/ 到 ima
→ 填入 kb_config.json
→ cd scripts → python kb_setup.py → 选择 ima 后端
→ 连接 WorkBuddy tencent-docs
→ 导入 9 个专家 Prompt
→ 开始使用
```

### 开源后不可用的能力

| 能力 | 原因 | 替代方案 |
|------|------|---------|
| 直接访问你的 ima 云端库 | 个人账号绑定 | 用户自建库 + 上传种子 |
| 公司资质/人员/业绩匹配 | 本地敏感数据 | 用户提供自己的 CSV |
| tencent-docs 自动排版 | 需 WorkBuddy + 连接器 | 输出 Markdown 手动转 Word |
| 历史标书范文 | 当前为空 | 社区贡献逐步积累 |
