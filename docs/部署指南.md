## 三种部署模式

| 模式 | 耗时 | 适合谁 | 包含内容 |
|------|------|--------|---------|
| **快速部署** | ~5 分钟 | 想立刻试用的个人用户 | 本地知识库 + 零依赖 |
| **标准部署** | ~15 分钟 | 日常使用的个人/小团队 | 虚拟环境 + 依赖安装 + 后端配置 |
| **完整部署** | ~30 分钟 | 需要团队协作的团队 | 标准部署 + ima 云端 + 渠道推送 |

## 模式一：快速部署（5分钟）

最快上手方式，零安装零配置。

```bash
# 1. 克隆项目
git clone https://github.com/tten3306879456/BidAgent-KB.git
cd BidAgent-KB

# 2. 运行快速部署向导
python scripts/setup_wizard.py --quick --skip-venv
```

向导会自动完成：
- ✅ 环境检查
- ✅ 基础依赖安装 (PyPDF2, requests)
- ✅ 本地知识库后端 (local_search)
- ✅ .env 配置生成
- ✅ 种子文件导入 (23 个)
- ✅ 搜索验证

部署完成后：

```bash
# 验证搜索
python scripts/kb_local_search.py "投标保证金"
```

### Step 1: 克隆项目

```bash
git clone https://github.com/tten3306879456/BidAgent-KB.git
cd BidAgent-KB
```

### Step 2: 运行部署向导

```bash
python scripts/setup_wizard.py
```


将 `expert_prompts/` 目录下的 9 个专家导入 WorkBuddy 专家中心。

## 模式三：完整部署（含渠道推送）

在标准部署基础上，增加 ima 云端知识库和消息推送渠道。

### Step 1-3: 同标准部署

```bash
git clone https://github.com/tten3306879456/BidAgent-KB.git
cd BidAgent-KB
python scripts/setup_wizard.py
```

在 Step 4 选择后端时，选择 `[2] ima 云端知识库` 或 `[3] 混合模式`。

### Step 4: 配置 ima 知识库

1. 注册 ima 账号：https://ima.qq.com
2. 创建知识库（建议按 6 座分类）
3. 将知识库 ID 填入配置

编辑 `kb_config.json`：

```json
{
  "backend": {
    "type": "ima",
    "ima": {
      "shared_kbs": {
        "标书法规库": "你的知识库ID",
        "标书案例库": "你的知识库ID",
        "投标文件编辑模板库": "你的知识库ID",
        "nuclear_industry": "你的知识库ID",
        "software_development": "你的知识库ID"
      }
    }
  }
}
```

或直接加入项目维护者的共享知识库（见 [README.md](../README.md#共享知识库)）。

### Step 5: 上传种子文件到 ima

```bash
cd scripts
cp .env.example .env
# 在 WorkBuddy 中调用 ima create_media 获取临时凭证，填入 .env
python cos_upload.py --file ../seeds/标书核心法规汇编_v1.0.md
# 在 WorkBuddy 中调用 ima add_knowledge 完成入库
rm .env  # 用完立即删除
```

批量上传参见 [scripts/README.md](../scripts/README.md#批量上传示例)。

### Step 6: 配置消息推送渠道

在部署向导的 Step 6 中选择配置渠道，或后续手动配置：

```bash
# 列出当前渠道状态
python scripts/channel_notify.py list

# 配置飞书（基础配置：只需 Webhook URL）
python scripts/channel_notify.py update feishu \
  FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your_hook \
  --save

# 如果开启了「签名校验」，额外配置加签 Secret
python scripts/channel_notify.py update feishu \
  FEISHU_BOT_SECRET=your_bot_secret \
  --save

# 测试连接
python scripts/channel_notify.py test feishu

# 发送测试消息
python scripts/channel_notify.py send "部署完成！" -c feishu
```

各渠道详细配置见 [消息推送渠道配置](#消息推送渠道配置) 章节。

## 知识库后端配置

### 后端对比

| 后端 | 适合场景 | 安装难度 | 是否需要网络 |
|------|---------|---------|------------|
| `local_search` | 个人/试用/离线 | ⭐ 无 | 否 |
| `ima` | 团队/社区共享 | ⭐⭐ 低 | 是 |
| `both` | 公共+私有混合 | ⭐⭐⭐ 中 | 是 |
| `chromadb` | 语义搜索/高级 | ⭐⭐⭐⭐ 高 | 否(首次需要) |

### 切换后端

修改 `kb_config.json` 中的 `backend.type` 字段，或运行：

```bash
python scripts/kb_setup.py --backend ima
```

### ChromaDB 高级后端

```bash
pip install chromadb sentence-transformers
python scripts/kb_setup.py --backend chromadb
```

首次运行会自动下载中文嵌入模型 BAAI/bge-large-zh-v1.5（~1.3GB），之后完全离线。
如需轻量替代，可在 kb_config.json 中改用 `sentence-transformers/all-MiniLM-L6-v2`（~90MB）。

## 消息推送渠道配置

支持飞书、钉钉、企业微信、微信公众号四个渠道，纯 Python 标准库实现，零第三方依赖。

### 渠道对比

| 渠道 | 推送方式 | 必填配置 | 可选配置 | 获取方式 |
|------|---------|---------|---------|---------|
| 飞书 | Webhook 机器人（支持加签） | `FEISHU_WEBHOOK_URL` | `FEISHU_BOT_SECRET`（开启签名校验时填写） | 飞书群 → 设置 → 群机器人 → 添加 → 自定义机器人 |
| 钉钉 | Webhook 机器人（支持加签） | `DINGTALK_WEBHOOK_URL` | `DINGTALK_APP_SECRET`（开启加签时填写） | 钉钉群 → 群设置 → 智能群助手 → 添加机器人 → 自定义 |
| 企业微信 | 应用消息 API | `WECOM_CORP_ID` + `WECOM_SECRET` + `WECOM_AGENT_ID` | 企业微信管理后台 → 应用管理 |
| 微信公众号 | 客服消息 API | `WECHAT_APP_ID` + `WECHAT_APP_SECRET` | 微信公众平台 → 开发 → 基本配置 |

### 配置方式

#### 方式一：CLI 配置（推荐）

```bash
# 飞书
python scripts/channel_notify.py update feishu \
  FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx \
  --save

# 钉钉（带加签）
python scripts/channel_notify.py update dingtalk \
  DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=xxxxx \
  DINGTALK_APP_SECRET=SECxxxxx \
  --save

# 企业微信
python scripts/channel_notify.py update wecom \
  WECOM_CORP_ID=ww1234567890 \
  WECOM_AGENT_ID=1000002 \
  WECOM_SECRET=your_secret \
  --save

# 微信公众号
python scripts/channel_notify.py update wechat \
  WECHAT_APP_ID=wx1234567890 \
  WECHAT_APP_SECRET=your_secret \
  --save
```

#### 方式二：编辑 .env 文件

在项目根目录 `.env` 文件中填写（参考 `.env.example`）：

```env
# 飞书
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx

# 钉钉
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=xxxxx
DINGTALK_APP_SECRET=SECxxxxx

# 企业微信
WECOM_CORP_ID=ww1234567890
WECOM_AGENT_ID=1000002
WECOM_SECRET=your_secret
```

#### 方式三：交互界面原型

打开 `docs/交互界面原型.html`，在「智能体设置」标签页的第 7 节「渠道配置」中填写，然后点击「导出配置」生成 `.env` 文件。

### 动态更新凭证

运行时动态更新凭证，无需重启服务：

```python
from channel_notify import load_notifiers, update_channel

notifiers = load_notifiers()
# 更新飞书加签密钥（未开启签名校验可跳过）
result = update_channel("feishu", {"FEISHU_BOT_SECRET": "new_secret"}, notifiers)
# 旧 access_token 缓存自动清除
```

CLI 方式：

```bash
# 内存中更新（不持久化）
python scripts/channel_notify.py update feishu FEISHU_BOT_SECRET=new_secret

# 更新后立即测试
python scripts/channel_notify.py update feishu FEISHU_WEBHOOK_URL=https://... --test

# 持久化到 .env
python scripts/channel_notify.py update feishu FEISHU_BOT_SECRET=new_secret --save
```

### 测试与发送

```bash
# 测试所有已配置渠道
python scripts/channel_notify.py test

# 测试单个渠道
python scripts/channel_notify.py test feishu

# 发送文本消息到所有渠道
python scripts/channel_notify.py send "标书审核完成，请查阅"

# 发送到指定渠道
python scripts/channel_notify.py send "消息内容" -c dingtalk

# Markdown 格式
python scripts/channel_notify.py send "## 标题\n正文内容" --markdown

# 指定接收人（企业微信/微信）
python scripts/channel_notify.py send "消息" --touser @all
```

## 常见问题排查

### Q: Python 版本不够

```bash
# 检查版本
python --version

# 升级 Python
# Windows: 从 python.org 下载安装
# macOS: brew install python@3.12
# Ubuntu: sudo apt install python3.12
```

### Q: 虚拟环境创建失败

```bash
# 方案1: 跳过虚拟环境
python scripts/setup_wizard.py --skip-venv

# 方案2: 手动创建
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
pip install -r requirements.txt
```

### Q: pip install 失败（网络问题）

```bash
# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或阿里云镜像
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple
```

### Q: 本地搜索无结果

```bash
# 重新导入种子文件
python scripts/kb_setup.py --backend local_search --quick

# 检查种子文件
ls -la seeds/*.md | wc -l  # 应该有 23 个以上

# 手动搜索测试
python scripts/kb_local_search.py "招标"
```

### Q: ima 上传失败

```bash
# 1. 检查 COS 凭证是否过期
# 临时凭证有效期通常只有数小时，需要在 WorkBuddy 中重新调用 create_media

# 2. 检查 .env 文件
cat scripts/.env  # 确认 COS_SECRET_ID 等字段已填写

# 3. 查看上传日志
python scripts/kb_sync_manager.py status
```

### Q: 渠道消息发送失败

```bash
# 检查渠道配置
python scripts/channel_notify.py list

# 测试连接（查看详细错误）
python scripts/channel_notify.py test feishu

# 常见原因：
# - 飞书: Webhook URL 过期或被禁用
# - 钉钉: 加签密钥不匹配
# - 企业微信: Secret 过期或 IP 白名单限制
# - 微信公众号: IP 白名单限制（需在公众平台配置服务器IP）
```

### Q: ChromaDB 安装失败

```bash
# ChromaDB 需要较多依赖，建议在虚拟环境中安装
python -m venv venv
source venv/bin/activate  # 或 venv\Scripts\activate (Windows)
pip install chromadb sentence-transformers

# 如果仍然失败，使用 local_search 后端即可
python scripts/kb_setup.py --backend local_search
```

### Q: Windows 下路径问题

```bash
# 使用正斜杠或双反斜杠
python scripts/kb_init.py "./kb_data"       # 推荐
python scripts/kb_init.py "D:\\BidAgent-KB\\kb_data"  # 也可以
```

## 安全提醒

1. **`.env` 文件切勿提交到 Git** — 已在 `.gitignore` 中忽略
2. **COS 临时凭证用完立即删除** — 有效期仅数小时
3. **敏感数据不上云** — 公司资质、人员信息、报价方案只存本地
4. **共享知识库只放公开内容** — 法规、标准、废标模式等脱敏知识
