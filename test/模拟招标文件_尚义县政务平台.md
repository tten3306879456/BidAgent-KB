### 二、投标人资格要求

#### 2.1 必备资格条件（不满足按废标处理）

1. 投标人须具有独立承担民事责任能力的法人或其他组织，提供有效的营业执照副本复印件。
2. 投标人须具备**计算机信息系统集成二级及以上资质**或**软件能力成熟度CMMI3级及以上认证**。
3. 投标人须具有**ISO27001信息安全管理体系认证证书**。
4. 投标人近三年（2023年1月至今）须至少完成**2个合同金额不低于200万元的政务信息化项目**业绩。
5. 投标人未被列入"信用中国"网站失信被执行人、重大税收违法案件当事人名单。
6. 本项目**不接受联合体投标**。
7. 投标人须按规定缴纳投标保证金 **人民币6万元**。

#### 2.2 加分资格条件

1. 投标人具有ISO9001质量管理体系认证证书的，加1分。
2. 投标人具有国家高新技术企业证书的，加1分。
3. 投标人近三年完成3个及以上政务信息化项目业绩的，加1分。

### 三、人员要求

#### 3.1 项目经理（1人）

- 具有PMP项目管理认证或信息系统项目管理师（高级）证书
- 具有5年以上信息化项目管理经验
- 近三年至少担任过1个合同金额不低于200万元的政务信息化项目经理

#### 3.2 技术负责人（1人）

- 具有高级工程师职称或同等技术资格
- 具有5年以上信息化系统架构设计经验
- 精通微服务架构、数据中台技术

#### 3.3 开发团队

- 前端开发工程师不少于2人，熟练掌握Vue或React
- 后端开发工程师不少于2人，熟练掌握Java/Spring生态
- 测试工程师不少于1人
- 安全工程师不少于1人，具有信息安全相关证书

### 四、技术规格要求

#### 4.1 功能需求

1. **统一身份认证平台**：实现省、市、县三级政务系统统一登录，支持SSO、OAuth2.0，支持数字证书、人脸识别等多种认证方式。
2. **政务服务事项管理系统**：实现政务服务事项的标准化管理，支持事项编码规则、办理流程配置、材料清单管理。
3. **一网通办门户**：建设PC端和移动端政务服务门户，支持事项查询、在线申报、进度查询、评价反馈。
4. **数据共享交换平台**：实现与省市数据共享交换平台对接，支持数据目录管理、数据订阅、数据推送。
5. **电子证照库**：建设县级电子证照库，支持证照信息采集、证照生成、证照验证。
6. **智能客服系统**：基于AI技术提供7×24小时智能问答服务，支持自然语言理解、知识库管理。

#### 4.2 性能需求

| 指标 | 要求 |
|------|------|
| 并发用户数 | ≥2000 |
| 响应时间 | 页面加载≤3秒，接口响应≤1秒 |
| 数据处理能力 | 日均办理量≥10000件 |
| 系统可用性 | ≥99.5% |
| 数据存储 | 支持至少500万条证照数据 |

#### 4.3 安全需求

1. 系统安全等级保护不低于**二级**。
2. 实现数据传输加密（HTTPS/TLS1.2以上）。
3. 实现操作审计日志，保留期限不少于6个月。
4. 实现数据备份策略，支持每日增量备份、每周全量备份。
5. 系统上线前须通过第三方安全测评。

#### 4.4 接口需求

1. 与河北省政务服务网对接（统一身份认证、事项同步）。
2. 与张家口市数据共享交换平台对接。
3. 与尚义县现有OA系统对接（待办推送、消息提醒）。
4. 预留与省级"冀时办"移动端对接接口。

### 五、商务要求

#### 5.1 交付周期

合同签订后 **6个月内**完成系统建设并上线试运行。

#### 5.2 付款方式

1. 合同签订后支付合同总价的30%预付款。
2. 系统上线试运行后支付合同总价的40%。
3. 终验合格后支付合同总价的25%。
4. 质保期满后支付合同总价的5%尾款。

#### 5.3 质保期

系统终验合格后**免费质保期不少于2年**。

#### 5.4 培训要求

- 对最终用户提供不少于3次集中培训。
- 对系统管理员提供不少于5个工作日的技术培训。
- 提供完整的用户手册和操作视频。

#### 5.5 售后服务

- 质保期内7×24小时响应，2小时内到达现场。
- 严重故障4小时内解决，一般故障24小时内解决。

### 七、投标文件格式要求

1. 投标文件一式叁份（正本壹份，副本贰份），电子版壹份（U盘）。
2. 投标文件须用A4纸打印，胶装成册。
3. 正本须逐页加盖投标人公章，封面加盖法定代表人签字和公章。
4. 投标文件包括：资格审查文件、商务标书、技术标书三部分，分别密封。
5. 投标文件须按招标文件规定的格式和顺序编制，不得自行调整。
6. 未按要求密封、签字、盖章的，投标无效。

### 八、废标条款汇总

1. 投标人未按规定时间递交投标文件的（逾期送达废标）。
2. 投标文件未按招标文件要求签字盖章的（格式不合规废标）。
3. 投标人资格要求不满足第2.1条任何一项的（资质不符废标）。
4. 投标报价超过项目预算金额的（报价异常废标）。
5. 投标有效期不足90日的（投标有效期不符废标）。
6. 投标保证金未按规定缴纳或金额不足的（保证金未缴纳废标）。
7. 投标文件未按要求分别密封的（格式不合规废标）。
8. 投标人存在串通投标行为的（串通投标废标）。
9. 投标人提供虚假材料的（弄虚作假废标）。
10. 项目经理或技术负责人不符合要求的（项目经理不符废标）。
11. 业绩不符合第2.1条第4款要求的（业绩要求不符废标）。
12. 投标人被列入失信被执行人名单的（信用记录不良废标）。
