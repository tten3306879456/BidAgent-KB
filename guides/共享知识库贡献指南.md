# 共享知识库贡献指南

## 一、共享什么？

本项目维护一个 **开放共享的 ima 知识库群**，包含 **6 个职责互斥的共享知识库**（2026-08-13 定稿为「3 通用底座 + 3 行业垂直库」）：

| # | 知识库 | 职责（互斥） | KB ID | 主要来源 |
|---|--------|------------|-------|---------|
| 1 | 📜 **标书法规库** | 招投标相关的**法律条文**（招标投标法、政府采购法、报价规则、保证金、新法规等） | `7493174142445773` | 官方发布 |
| 2 | ⚠️ **标书案例库** | **废标案例**（废标条款模式、历史典型废标案例、资质等效经验） | `7493174285050353` | 项目积累+公开通报 |
| 3 | 📋 **投标文件编辑模板库** | **投标文件编辑模板**（章节结构模板、撰写框架、范文片段） | `7493174465429392` | 脱敏社区贡献 |
| 4 | 🏭 **核工业标书知识库** | **核工业领域标准**（HAF法规、GBZ117、核安全许可证、资质等效） | `7493159651146811` | 官方发布+项目积累 |
| 5 | 💻 **软件开发标书知识库** | **软件行业领域标准**（软件工程、政务信息化、数据安全、等保、信创） | `7493159953137267` | 官方发布+项目积累 |
| 6 | ⚙️ **设备采购知识库** | **设备采购领域知识**（87号令要点、机械设备/信息化/实验室/安防技术标准、设备投标模板、设备废标案例） | `7493501189104652` | 官方发布+项目积累 |

> ⚠️ **6 库职责互斥**：每条知识只应归属一个库。若不确定，先看关键字：
> - 法律条文 → 法规库
> - 废标案例 → 案例库
> - 投标模板/范文 → 模板库
> - 软件行业国标/行标 → 软件开发库
> - 核工业国标/行标 → 核工业库
> - 设备采购资料（87号令/设备标准/设备模板/设备案例） → 设备采购库


## 二、不共享什么？

以下内容 **严禁上传到共享知识库**：

- ❌ 公司资质证书编号、营业执照编号
- ❌ 人员姓名、身份证号、联系方式
- ❌ 具体报价金额
- ❌ 未脱敏的技术方案原文
- ❌ 客户名称和项目名称
- ❌ 任何包含商业机密的内容

## 三、贡献流程

```
1. 准备内容 → 按.md模板编写
2. 脱敏处理 → 去除敏感信息（见第四节）
3. 提交PR → 附上内容说明
4. 审核合并 → 维护者审核后合入共享库
5. 自动同步 → 更新到 ima 公共知识库
```

## 四、脱敏规范

### 4.1 投标文件编辑模板脱敏

| 原文 | 脱敏后 |
|------|--------|
| 项目名称："XX市公安局智慧警务系统" | 项目名称：[客户名称]智慧[业务领域]系统 |
| 公司名："XX科技有限公司" | 公司名：[投标人公司名称] |
| 报价："1,280,000元" | 报价：[报价金额]元 |
| 人员："张三，高级工程师，证书编号XXXX" | 人员：[姓名]，[职称]，证书编号[已验证] |
| 地址："XX市XX区XX路XX号" | 地址：[项目实施地址] |

### 4.2 范文片段格式

贡献标书范文时，按以下格式编写 .md 文件：

```markdown
### [范文标题]

**适用场景**: 描述这个范文适合什么类型的标书
**所属段落**: 商务标书 / 技术标书 / 报价方案
**评分要点**: 这个段落可能命中哪些评分项

---

[范文正文，已脱敏]

---

**贡献者**: @github用户名
**审核状态**: 待审核 / 已审核
**版本**: v1.0
**日期**: YYYY-MM-DD
```

## 五、ima 公共知识库使用

### 维护者信息

- **公共知识库名称**: 标书智能体共享知识库
- **加入方式**: 开放加入（所有用户可检索，不可修改）
- **维护者**: 项目维护团队
- **更新频率**: 每月1次（随月度同步提醒一起处理）

### 新用户接入

1. 在 `kb_config.json` 或 `.env` 中填写 `public_kb_id`
2. 运行 `python kb_setup.py` 初始化
3. 专家即可检索公共知识库内容

### 向公共库贡献

1. Fork 项目仓库
2. 在 `shared_content/` 目录下添加 .md 文件
3. 提交 Pull Request，附上内容说明和脱敏声明
4. 维护者审核通过后，合入并同步到 ima 公共库

## 六、五类共享内容详解

### 6.1 标书法规库（ID: 7493174142445773）

**职责边界**: 仅收录招投标相关的**法律、行政法规、部门规章、规范性文件、配套规章**。不含技术标准（→ 软件开发库或核工业库）、不含判例（→ 案例库）。

**已有内容**:
- 标书核心法规汇编（招标投标法、政府采购法等5部）
- 招投标报价与商务法规专题库（报价规则、保证金、中小企业政策）
- 标书法规库_2024-2025新增法规（8部新出台/修订法规，含公平竞争审查规则/条例、国办发〔2024〕21号、政府采购三年行动方案、招标投标法修订草案、政府采购法修订草案、网络数据安全管理条例、2025年等保工作新要求）

**如何扩充**:
- 上传法规 PDF 原文 → `python kb_auto_index.py "法规文件.pdf"` → 自动生成摘要
- 在 .md 文件中追加法规条文要点（按"发布机关、施行日期、核心要点、标书响应要点"四要素）
- 贡献地方法规、行业专项规章

### 6.2 标书案例库（ID: 7493174285050353）

**职责边界**: 仅收录**废标条款模式 + 典型废标案例 + 资质等效经验**。不含法律法规（→ 法规库）、不含新招标制度（→ 法规库）。

**已有内容**:
- 15条废标模式（DQ-001~DQ-015）
- IT行业资质等效替代规则（人员证书等效、业绩等效）
- 标书案例库_2024-2025典型案例（10个典型废标/违法违规案例，含串通投标、弄虚作假、资格审查错误等）

**如何扩充**:
- 遇到新的废标条款 → 按 DQ-0XX 格式编写模式
- 包含：触发关键词、表述模式、法律依据、严重等级、正例、反例
- 提交 PR 补充到 `废标条款模式库_种子版.md`

### 6.3 投标文件编辑模板库（ID: 7493174465429392）

**职责边界**: 仅收录**投标文件的撰写模板、章节结构、范文片段**（如封面、目录、应答骨架、报价表说明、承诺函模板）。不含技术标准（→ 行业库）、不含废标案例（→ 案例库）。

**当前状态**: ✅ **已入库 4 个模板文件**（互联网搜集整理）

**已有内容**:
- 投标文件通用框架与封面模板.md — 标准目录结构（通用/工程/信息化三类）、封面格式、编排装订规范
- 商务标书模板_投标函与响应表.md — 投标函/授权书/报价表/开标一览表/信息化项目报价表模板
- 技术标书模板_信息化项目方案框架.md — 信息化项目技术方案五章框架（项目理解/技术方案/实施/质量保障/培训运维）
- 评分响应与偏离表模板集.md — 技术偏离表/商务偏离表/评分索引表/业绩表/团队表/承诺函/中小企业声明函模板

**如何扩充**（按贡献流程执行）:
1. 从实际标书中提取脱敏范文片段（见第四节"脱敏规范"）
2. 按下面的"范文片段格式"编写
3. 放入 `shared_content/标书范文/` 目录
4. 可按类型分：商务标书范文、技术方案范文、报价方案范文

**模板目录结构**:
```
shared_content/
└── 标书范文/
    ├── 商务标书/
    │   ├── 公司简介_范文.md
    │   ├── 团队配置_范文.md
    │   ├── 商务条款响应_范文.md
    │   └── 服务承诺_范文.md
    ├── 技术标书/
    │   ├── 技术方案总述_范文.md
    │   ├── 详细技术方案_范文.md
    │   ├── 实施步骤_范文.md
    │   ├── 进度计划_范文.md
    │   ├── 质量保障_范文.md
    │   └── 风险应对_范文.md
    └── 报价方案/
        └── 报价方案_范文.md
```

**关键原则**: 真实性高 + 脱敏彻底 = 该库的入库标准。不会因为你的模板多而扣分，反而会因为过短、无信息含量而降级。

### 6.4 软件开发标书知识库（ID: 7493159953137267）

**职责边界**: 仅收录**软件开发/政务信息化/系统集成类项目相关的技术标准**。不含核工业标准（→ 核工业库）、不含招投标法规（→ 法规库）。

**已有内容**:
- 软件开发标书知识库_种子版（GB/T 软件工程、CMMI、ISO 27001、ITSS 等）
- 行业技术标准_软件开发部分（等保2.0、数据安全、个人信息保护、政务信息化、云计算、ISO 27001 等通用软件标准）
- 软件行业标准_2024-2025更新（GB/T 45396-2025、GB/T 43697-2024、GB/T 45577-2025、GB/T 45574-2025、信创标准、等保81项高风险判例等 9 项新标准）

**如何扩充**:
- 关注 GB/T、JR/T、YD/T、T/ISEAA 等系列标准更新
- 编写标准要点（按"标准编号、适用场景、核心要求、标书响应要点"四要素）
- 通用行业标准归本库（如 GB/T 22239 等保、GB/T 35273 个保）
- 行业专有标准按需归对应行业库

### 6.5 核工业标书知识库（ID: 7493159651146811）

**职责边界**: 仅收录**核工业/核设施/核安全/放射防护相关的技术标准**。不含软件开发标准（→ 软件开发库）、不含招投标法规（→ 法规库）。

**已有内容**:
- 核工业标书知识库_种子版（核安全法规、HAF许可证、核工业资质等效、核级软件等）

**如何扩充**:
- 关注 HAF（核安全法规）、GBZ（放射防护）、EJ/T（核工业行业标准）的更新

- 跨行业引用本库（如 软件开发涉及核工业项目时）
