# 共享知识库贡献指南

## 一、共享什么？

本项目维护一个 **开放共享的 ima 知识库**，包含 3 类公共知识：

| 类别 | 内容 | 来源 | 谁可贡献 |
|------|------|------|---------|
| 📜 法律法规库 | 招标投标法、政府采购法、报价规则等法规条文 | 官方发布 | 所有人 |
| ⚠️ 废标条款模式 | 招标文件中常见的废标条款模式（触发词、法律依据、严重等级） | 项目积累 | 所有人 |
| 📝 标书模板/范文 | 脱敏后的标书模板、技术方案范文片段 | 社区贡献 | 所有人 |

## 二、不共享什么？

以下内容 **严禁上传到共享知识库**：

- ❌ 公司资质证书编号、营业执照编号
- ❌ 人员姓名、身份证号、联系方式
- ❌ 具体报价金额
- ❌ 未脱敏的技术方案原文
- ❌ 客户名称和项目名称
- ❌ 任何包含商业机密的内容

## 三、贡献流程

```
1. 准备内容 → 按.md模板编写
2. 脱敏处理 → 去除敏感信息（见第四节）
3. 提交PR → 附上内容说明
4. 审核合并 → 维护者审核后合入共享库
5. 自动同步 → 更新到 ima 公共知识库
```

## 四、脱敏规范

### 4.1 标书模板脱敏

| 原文 | 脱敏后 |
|------|--------|
| 项目名称："XX市公安局智慧警务系统" | 项目名称：[客户名称]智慧[业务领域]系统 |
| 公司名："XX科技有限公司" | 公司名：[投标人公司名称] |
| 报价："1,280,000元" | 报价：[报价金额]元 |
| 人员："张三，高级工程师，证书编号XXXX" | 人员：[姓名]，[职称]，证书编号[已验证] |
| 地址："XX市XX区XX路XX号" | 地址：[项目实施地址] |

### 4.2 范文片段格式

贡献标书范文时，按以下格式编写 .md 文件：

```markdown
### [范文标题]

**适用场景**: 描述这个范文适合什么类型的标书
**所属段落**: 商务标书 / 技术标书 / 报价方案
**评分要点**: 这个段落可能命中哪些评分项

---

[范文正文，已脱敏]

---

**贡献者**: @github用户名
**审核状态**: 待审核 / 已审核
**版本**: v1.0
**日期**: YYYY-MM-DD
```

## 五、ima 公共知识库使用

### 维护者信息

- **公共知识库名称**: 标书智能体共享知识库
- **加入方式**: 开放加入（所有用户可检索，不可修改）
- **维护者**: 项目维护团队
- **更新频率**: 每月1次（随月度同步提醒一起处理）

### 新用户接入

1. 在 `kb_config.json` 或 `.env` 中填写 `public_kb_id`
2. 运行 `python kb_setup.py` 初始化
3. 专家即可检索公共知识库内容

### 向公共库贡献

1. Fork 项目仓库
2. 在 `shared_content/` 目录下添加 .md 文件
3. 提交 Pull Request，附上内容说明和脱敏声明
4. 维护者审核通过后，合入并同步到 ima 公共库

## 六、三类共享内容详解

### 6.1 法律法规库

**已有内容**:
- 标书核心法规汇编（招标投标法、政府采购法等5部）
- 招投标报价与商务法规专题库（报价规则、保证金、中小企业政策）

**如何扩充**:
- 上传法规 PDF 原文 → `python kb_auto_index.py "法规文件.pdf"` → 自动生成摘要
- 在 .md 文件中追加法规条文要点
- 贡献地方法规、行业专项规章

### 6.2 废标条款模式库

**已有内容**: 15条废标模式（DQ-001~DQ-015）

**如何扩充**:
- 遇到新的废标条款 → 按 DQ-0XX 格式编写模式
- 包含：触发关键词、表述模式、法律依据、严重等级、正例、反例
- 提交 PR 补充到 `废标条款模式库_种子版.md`

### 6.3 标书模板/范文

**当前状态**: 待建设（需社区贡献）

**如何贡献**:
- 从实际标书中提取脱敏范文
- 按上面的"范文片段格式"编写
- 放入 `shared_content/标书范文/` 目录
- 可按类型分：商务标书范文、技术方案范文、报价方案范文

**模板目录结构**:
```

│   │   ├── 商务条款响应_范文.md
│   │   └── 服务承诺_范文.md
│   ├── 技术标书/
│   │   ├── 技术方案总述_范文.md
│   │   ├── 详细技术方案_范文.md

│   │   ├── 进度计划_范文.md
│   │   ├── 质量保障_范文.md
```
