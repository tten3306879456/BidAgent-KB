📋 详细部署步骤
1

2

打开终端（CMD/PowerShell），进入项目目录，执行一键部署命令。向导会自动安装依赖、生成配置、初始化知识库。

❓ 常见问题
Q: 没有编程基础能部署吗？
可以！只需安装 Python，然后复制粘贴 3 条命令即可完成部署。部署向导会自动处理所有配置。
Q: 部署需要联网吗？
部署时需要联网下载依赖包（约 50MB）。部署完成后，本地检索和知识库完全离线可用。
Q: 支持 macOS / Linux 吗？
完全支持。项目纯 Python 实现，跨平台兼容。命令在所有操作系统上通用。
Q: 数据安全吗？
所有数据存储在本地电脑，不上传任何文件到云端。可选的云端知识库需要你自己配置腾讯云 COS 密钥。
Q: 如何选择检索后端？
默认使用本地搜索（零依赖）。如需 AI 语义搜索，运行 python scripts/setup_wizard.py 选择 ChromaDB 后端，会自动下载嵌入模型（约 1.3GB）。
Q: 如何配置消息推送渠道？
运行 python scripts/channel_notify.py list 查看渠道状态，然后在 .env 文件中填入对应渠道的 Webhook 地址和密钥即可。
