⚠️ 前置要求
部署前请确认已安装：
• Python 3.8+ — 官方下载（安装时勾选 Add to PATH）
• Git（可选）— 官方下载
• 操作系统 — Windows / macOS / Linux 均可
• 无需 GPU — CPU 即可运行全部功能
📋 详细部署步骤
1
获取项目代码
点击上方「打开 Gitee 仓库」或「下载 ZIP」，将项目保存到电脑任意目录。
2
运行部署向导
打开终端（CMD/PowerShell），进入项目目录，执行一键部署命令。向导会自动安装依赖、生成配置、初始化知识库。
3
验证搜索功能
执行搜索命令，如果返回知识库匹配结果，说明部署成功！
4
打开管理控制台（可选）
运行 python scripts/kb_console.py 打开浏览器可视化控制台，查看知识库覆盖度、上传文件、配置消息推送渠道。
5
导入 WorkBuddy 使用
将 expert_prompts/ 目录中的专家 Prompt 复制到 WorkBuddy 专家中心，即可开始与标书智能体对话。
❓ 常见问题
Q: 没有编程基础能部署吗？
可以！只需安装 Python，然后复制粘贴 3 条命令即可完成部署。部署向导会自动处理所有配置。
Q: 部署需要联网吗？
部署时需要联网下载依赖包（约 50MB）。部署完成后，本地检索和知识库完全离线可用。
Q: 支持 macOS / Linux 吗？
完全支持。项目纯 Python 实现，跨平台兼容。命令在所有操作系统上通用。
Q: 数据安全吗？
所有数据存储在本地电脑，不上传任何文件到云端。可选的云端知识库需要你自己配置腾讯云 COS 密钥。
Q: 如何选择检索后端？
默认使用本地搜索（零依赖）。如需 AI 语义搜索，运行 python scripts/setup_wizard.py 选择 ChromaDB 后端，会自动下载嵌入模型 bge-large-zh-v1.5（约 1.3GB，中文语义检索效果更精准）。
Q: 管理控制台有什么用？
运行 python scripts/kb_console.py 打开可视化控制台，可以在浏览器中查看知识库覆盖度、上传文件、配置消息推送渠道，无需手动编辑配置文件。
Q: 如何配置消息推送渠道？
飞书：在群聊中添加自定义机器人，获取 Webhook URL 填入即可（加签密钥可选）。钉钉/企微/微信类似。可通过管理控制台可视化配置，或运行 python scripts/channel_notify.py list 查看。
