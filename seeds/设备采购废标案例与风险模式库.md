# 设备采购废标案例与风险模式库（种子版 v1.0）

> 本文件收录设备采购类项目真实废标/无效投标案例与高频风险模式，供标书审核专家和编写专家规避风险。
> 每个案例标注：风险模式、失败原因、规避策略。

---

## 一、真实案例

### 案例 1：CT 成像核心部件不同品牌 → 实质性条款负偏离 → 投标无效（2025年）

**项目背景**：某医院 CT 设备采购项目，综合评分法。

**废标原因**：两家投标人投标产品中"CT 成像核心部件（球管、高压发生器、探测器）为同品牌"项为**负偏差**，按照招标文件《采购货物技术参数及要求》中"实质性条件不满足或负偏离的，视为不能满足招标文件的实质性要求，投标文件无效"的规定，认定投标文件无效。最终通过符合性审查的供应商不足 3 家，项目流标。

**风险模式**：DQ-003（技术参数排他/未响应实质性条款）
- 招标文件明确标注的实质性条款（如核心部件同品牌要求）负偏离 = 投标无效；
- 投标前必须逐条核对 ★/▲ 实质性条款，对无法满足的条款须在答疑期提出质疑或放弃投标。

**规避策略**：
1. 投标前用"实质性条款清单"逐条自检；
2. 对招标文件的显失公平条款（如品牌捆绑）在法定质疑期内书面质疑；
3. 代理投标时确认所代理产品完全满足全部实质性条款再投标。

### 案例 2：技术响应表未完整填写 → 未实质响应 → 废标（2026年）

**项目背景**：某高校实验室设备采购项目。

**废标原因**：3 家投标人"未按照采购需求货物清单填写全部的货物参数，仅对招标文件部分货物清单参数进行响应"，不满足招标文件"在任一单个产品/设备项下，负偏离或未响应的条款累计超过 3 项（含），视为未实质性响应采购需求；或在全部产品/设备项下，负偏离或未响应的条款累计总数超过 25 项（含），视为未实质性响应采购需求"的规定，被评标委员会废标。实质性响应供应商不足规定数量，采购终止。

**风险模式**：DQ-014（响应缺失/遗漏条款）
- **漏响应 = 未响应**：技术响应表必须覆盖货物清单的全部参数，缺一行都可能触发累计超限规则；
- 参数条目多的项目（几十上百项）极易遗漏，务必用清单逐行核对。

**规避策略**：
1. 用脚本/表格工具将招标参数清单转为响应表骨架，逐行填写，不留空行；
2. 响应表与招标参数条款号一一对应；
3. 双人复核：编写人填写 + 审核人逐条比对招标原文。

### 案例 3：★条款证明材料模糊/不符合要求 → 未响应实质性要求 → 废标（2026年）

**项目背景**：某工业数字化技术实训中心设备采购项目。

**废标原因**：
1. 投标人 A 技术偏离表中"工业网络智能控制与维护工作站-运动执行单元-变频器及电机"提供的证明材料**模糊，无法证明参数是否符合招标文件要求**，未响应招标文件实质性要求；
2. 投标人 A 另一项"步进驱动器和电机（★条款：电机步距角≥1.8°，位置精度≤±0.9°）"提供的证明材料**不符合招标文件要求**，未响应实质性要求；
3. 投标人 B 技术偏离表**未按给定格式及填表要求填写、未按规定签章**。
通过符合性检查的供应商不足 3 家，项目废标。

**风险模式**：DQ-008（证明材料缺失/造假）、DQ-013（格式与签章不合规）
- 实质性条款（★）必须有**清晰、有效、对应**的证明材料（检测报告、制造商参数页），模糊/不对应 = 未响应；
- 偏离表格式、签章是符合性审查的硬性要求，形式瑕疵直接废标。

**规避策略**：
1. 证明材料扫描件确保清晰可辨，关键参数用高亮标记定位；
2. 证明材料必须能**直接证明对应条款参数**，不能张冠李戴；
3. 偏离表严格套用招标文件给定模板，逐页签章（骑缝章+落款章）。

### 案例 4：改装设备不满足"合法上牌"实质性条款 → 中标结果无效（典型案例）

**项目背景**：某单位排水车政府采购项目，A 公司中标后被 B 公司质疑投诉。

**处理结果**：财政部门审理认定，中标产品为**改装后未经备案、依法不能上牌**的车辆，不符合招标文件"在采购地可合法上牌"的实质性条款要求，认定该投标行为无效。

**风险模式**：DQ-015（合规性不符）
- 特种车辆、特种设备存在**准入/备案/上牌**等合规要求（车辆公告、CCC、生产许可），属于实质性条款；
- 改装车、贴牌车、未备案产品即使参数满足也可能因合规问题无效。

**规避策略**：
1. 投标前核实产品是否具备**合法准入资格**（公告目录、备案证明、许可证）；
2. 特种设备提供对应的强制认证与检验合格证明；
3. 在投标函中明确承诺产品在采购地可合法使用。

### 案例 5：实质性条款 vs 非实质性条款的认定争议（典型判例）

**项目背景**：某单位环卫车辆及配套设备采购项目，C 公司中标后被 D 公司质疑——C 公司产品不符合招标文件"采用链条式翻斗装置"的要求。

**处理结果**：财政部门审理认定，"链条式翻斗装置"**不属于招标文件实质性条款**，该指标按评分规则处理不影响中标结果，认定原中标结果有效。

**对照案例**：另一项目中招标文件对内窥镜"弯曲度 180 度"未标注为实质性条款，评委以"明显不符合技术参数要求属重大偏差"为由认定无效——评委对非标注条款是否构成重大偏离存在裁量空间。

**风险模式**：DQ-016（实质性条款识别不清）
- 是否实质性条款，以**招标文件醒目标注**（★/▲/加粗）为准，但评委对影响使用性能的重大负偏离有裁量权；
- 投标时对未标注的条款也不能随意负偏离，尤其影响核心功能的参数。

**规避策略**：
1. 全部条款（含未标注的）尽量满足，正偏离为佳；
2. 无法满足且非标注条款时，评估风险：是否影响核心功能？是否可能被评委认定为重大偏差？
3. 关键功能参数即使未加星也要当作实质性条款对待。

## 二、设备采购高频废标风险模式汇总

| 编号 | 风险模式 | 典型表现 | 规避要点 |
|------|---------|---------|---------|
| EQ-001 | 实质性条款负偏离 | ★/▲/加粗条款不满足（参数、合规、品牌捆绑） | 逐条自检实质性条款清单 |
| EQ-002 | 响应条款遗漏 | 技术响应表未覆盖全部参数，累计超限 | 清单逐行核对，不留空行 |
| EQ-003 | 证明材料不合格 | 模糊、不对应、非第三方、过期 | 清晰扫描+高亮定位+对应条款 |
| EQ-004 | 偏离表格式/签章瑕疵 | 未按给定格式、未签章 | 套用模板、骑缝章+落款章 |
| EQ-005 | 同品牌竞争合并 | 多投标人同品牌，按1家计算 | 代理前确认同品牌参与情况 |
| EQ-006 | 报价错误 | 大小写不一致、分项汇总错误、超最高限价 | 三遍复核报价 |
| EQ-007 | 制造商授权问题 | 无授权/过期/非本项目/多代理商 | 提前取得针对本项目的授权原件 |
| EQ-008 | 合规准入缺失 | 特种车辆不能上牌、设备无3C/防爆合格证 | 核实准入资质与认证 |
| EQ-009 | 样品不达标 | 样品与投标产品不一致/样品不合格 | 样品与响应参数完全一致 |
| EQ-010 | 投标有效期不足 | 承诺有效期短于招标要求 | 与招标文件核对有效期 |

## 三、设备采购标书自检清单（投标前）

- [ ] 实质性条款（★/▲/加粗）逐条响应且无负偏离
- [ ] 技术响应表覆盖全部货物清单参数（无遗漏）
- [ ] 所有重要参数附清晰、对应、有效的证明材料
- [ ] 技术偏离表按招标给定格式填写并完整签章
- [ ] 分项报价汇总=开标一览表总报价，大小写一致，未超最高限价
- [ ] 制造商授权书（代理投标时）为本项目出具且有效
- [ ] 产品具备合规准入资格（公告/3C/防爆/许可等）
- [ ] 投标有效期、质保期、交货期满足招标要求
- [ ] 中小企业声明函（如适用）按给定格式填写
- [ ] 保证金金额、形式、账户正确，按时到账
