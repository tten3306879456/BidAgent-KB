# 核工业投标文件模板集（种子版 v1.0）

> 本文件提供核工程、核设施改造、放射防护、核级设备类项目投标文件的标准模板与填写要点，参照核电 EPC/技术服务/放射防护项目招标常见要求整理。
> 供技术标书编写专家、文档排版专家直接套用，与《核工业废标案例与风险模式库》配合使用。

---

## 一、核工业项目投标文件整体结构

```
第一部分 商务文件
  一、投标函（核工业版）
  二、法定代表人身份证明 / 授权委托书
  三、投标保证金（保函/凭证）
  四、资格证明文件（重点：HAF许可/安全生产许可/辐射安全许可/注册核安全工程师）
     ├─ 营业执照
     ├─ 民用核安全设备设计/制造/安装/无损检验许可证（HAF601/602/603）
     ├─ 安全生产许可证
     ├─ 辐射安全许可证（正本含核素种类/活动种类/地址）
     ├─ 质量管理体系（ISO 9001/HAF003 质保体系认证）
     └─ 核安全许可适配性说明表（许可文号/堆型/阶段/有效期）
  五、财务审计报告（近三年，三表齐全）
  六、业绩证明（按"三同原则"：同堆型/同阶段/同角色）
  七、商务条款偏离表
  八、项目报价（开标一览表 + 分项报价）

第二部分 技术文件
  一、项目理解与总体方案
  二、技术方案（技术路线/系统集成/专项方案）
  三、质量保证大纲（HAF003 核质保体系）
  四、安全与辐射防护方案
  五、项目实施计划（进度/组织/现场管理）
  六、物项与设备方案（核级设备质控/采购/验证）
  七、培训与售后服务
  八、技术偏离表（逐条响应）
```

## 二、关键模板

### 2.1 投标函（核工业版）

```
致：＿＿＿＿＿＿＿＿（招标人/采购代理机构）

根据贵方项目编号为＿＿＿＿＿＿的《＿＿＿＿＿＿项目招标文件》，我方正式提交投标文件，
并作出如下承诺：

1. 我方已仔细阅读并完全理解招标文件全部内容，愿意按招标文件要求完成项目。
2. 我方投标总报价为人民币（大写）＿＿＿＿＿＿元整（¥＿＿＿＿＿＿），
   工期＿＿＿日历天，质保期＿＿＿个月。
3. 我方承诺具备完成本项目所需的核安全相关许可资质（HAF601/602/603、安全生产许可、
   辐射安全许可等），许可范围覆盖本项目全部招标内容。
4. 我方承诺按《中华人民共和国核安全法》及 HAF003《核电厂质量保证安全规定》建立并执行
   质量保证体系，确保工程质量与核安全。
5. 我方承诺遵守核电现场安全管理规定，接受贵方及监管部门的监督与检查。
6. 我方承诺本投标文件内容真实、合法、有效，如有虚假愿承担相应法律责任。

投标人（盖章）：＿＿＿＿＿＿
法定代表人或授权代表（签字）：＿＿＿＿＿＿
日期：＿＿年＿＿月＿＿日
```

**填写要点**：核工业投标函必须包含**资质覆盖承诺**与**HAF003 质保承诺**，这两项是评标关注重点。

### 2.2 核安全许可适配性说明表（资格文件核心页）

| 许可名称 | 许可文号 | 许可范围（堆型/设备类别/阶段） | 有效截止日 | 是否覆盖本项目 |
|---------|---------|-------------------------------|-----------|--------------|
| 民用核安全设备安装许可证 | HAF602-XXX | CAP1400 堆型/核级设备安装 | 20XX-XX-XX | ☑ 覆盖 |
| 安全生产许可证 | ＿＿＿＿ | 建筑施工/安装 | 20XX-XX-XX | ☑ 覆盖 |
| 辐射安全许可证 | ＿＿＿＿ | 核素：＿＿/活动种类：＿＿ | 20XX-XX-XX | ☑ 覆盖 |
| 注册核安全工程师 | ＿＿＿＿ | 人员：＿＿（项目负责人） | 20XX-XX-XX | ☑ 覆盖 |

**填写要点**：此表必须单独成页、在扫描件中标注页码索引；有效期覆盖工期全部关键节点；任何一项"不覆盖"须在答疑期澄清或放弃投标。

### 2.3 业绩证明表（三同原则）

| 项目名称 | 堆型代码 | 项目阶段 | 我方角色 | 合同金额 | 质保等级 | 证明文件 |
|---------|---------|---------|---------|---------|---------|---------|
| ＿＿＿核电3、4号机组冷源改造 | HPR1000 | 热试阶段 | EPC 联合体成员 | ＿＿万 | QSR | 合同+技术协议+验收 |
| ＿＿＿核级设备供货 | CAP1400 | 建造许可阶段 | 牵头方 | ＿＿万 | QSA | 合同+质保等级说明 |

**填写要点**：每项业绩须满足"同堆型、同阶段、同角色"；核级设备业绩必须附**质保等级说明与质量控制文件**（废标案例 4 的教训）；名称写全称，附堆型参数页。

### 2.4 项目理解与总体方案（技术标第一章）

```
一、项目背景与建设目标（结合核设施运营/监管背景）
二、项目特点与实施环境分析
  2.1 核安全管控区域作业限制（审批备案/安保要求/辐射防护分区）
  2.2 施工窗口期约束（机组大修窗口/运行连续性）
  2.3 行业法规与监管要求（核安全法/HAF系列/监管机构）
三、总体建设思路与技术路线
  3.1 总体原则（核安全第一/可靠性优先/可追溯管理）
  3.2 技术路线设计（与招标技术路线一致，不得用通用条款替代）
四、重点难点分析及应对措施
  4.1 放射性环境作业防护
  4.2 核级设备安装/检验特殊要求
  4.3 与在运机组接口协调
```

**填写要点**：本项目的"专用条款"必须逐条响应，**严禁用通用标准替代核岛专用参数**（如招标要求"响应时间≤12秒"，不能只写"满足 GB 50116"）；重点难点要结合项目真实环境（海水/辐射/窗口期等）。

### 2.5 质量保证大纲（HAF003 核质保体系）

```
一、质量保证政策与目标（核安全文化声明）
二、质量保证组织机构与职责（QA/QC 独立监督）
三、质保大纲内容（参照 HAF003 十三要素）
  3.1 组织  3.2 质量保证大纲  3.3 设计控制
  3.4 采购控制  3.5 物项控制  3.6 工艺过程控制
  3.7 检验与试验控制  3.8 测量与试验设备控制
  3.9 不符合项控制  3.10 纠正措施
  3.11 质量保证记录  3.12 监查
四、与甲方质保体系接口（接受甲方 QA 监督）
五、经验反馈（核安全经验反馈体系/FAA 数据库对接）
```

**填写要点**：质保大纲是核工业技术标的灵魂，必须引用 HAF003 具体要素条款；QA/QC 独立于生产部门；提供质保体系认证文件。

### 2.6 安全与辐射防护方案（技术标）

```
一、安全管理体系
  1.1 安全管理组织与责任（专职安全员/班前教育/隐患排查台账）
  1.2 现场安全规程遵守（甲方 EHS 规定/作业申请审批制）
  1.3 应急响应预案（辐射应急/消防/人员伤害/极端天气）
二、辐射防护方案
  2.1 辐射防护分区与管控（控制区/监督区）
  2.2 屏蔽设计（材料/厚度/依据标准 GBZ 117 等）
  2.3 个人剂量监测（剂量计/剂量档案/年剂量限值）
  2.4 放射性废物管理（分类/收集/暂存/移交）
三、环境保护措施（废水/废气/固废/噪声）
```

**填写要点**：放射防护项目要引用《电离辐射防护与辐射源安全基本标准》及 GBZ 系列标准；应急响应要有可演练的流程；人员防护装备清单明确。

### 2.7 项目实施计划与现场管理（技术标）

```
一、项目组织架构
  1.1 现场管理团队（项目经理/技术负责人/施工主管/安全员/质检员/文控员）
  1.2 关键人员资质（注册核安全工程师/核级焊工/RT-UTⅢ级无损检测人员）
二、进度计划
  2.1 WBS 分解 + 里程碑（关键路径识别）
  2.2 进度保障（周报/月度协调会/偏差预警/加班预案）
三、现场管理
  3.1 工作面分区管理与工序交接验收
  3.2 核电厂接口协同（固定联络人/作业申请/入场培训）
  3.3 到岗率与人员变动承诺
```

**填写要点**：关键人员（注册核安全工程师、核级焊工、无损检测人员）资质证书+社保证明必须齐全；到岗率承诺要写死（如"关键人员到岗率≥95%"）；现场管理制度要响应甲方"进出控制区审批备案"要求。

### 2.8 物项与设备方案（核级设备类项目）

```
一、核级设备采购与质控
  1.1 供应商资质核查（HAF601/602/603 + 全国核安全设备监管信息平台一致性）
  1.2 采购控制程序（质保等级/不符合项处理/见证点）
二、设备制造与检验
  2.1 制造工艺控制（焊接/热处理/无损检验 UT-RT-PT-MT）
  2.2 出厂试验与第三方检测
  2.3 性能测试与工况模拟
三、运输与现场安装
  3.1 装卸运输防护（专用工装/防震/辐射防护）
  3.2 现场安装工艺与调试
  3.3 备品备件与应急供货
```

**填写要点**：核级设备须附质保等级（QSA/QSR/QSS）说明；检测人员资质（RT/UT Ⅲ级）证书；材料须与监管平台数据一致（动态比对时间戳）。

### 2.9 培训与售后服务（技术标）

```
一、培训方案（运行操作/维护保养/辐射防护/应急演练，含教材与考核）
二、售后服务
  2.1 质保期服务（响应时限/故障分级/远程+现场）
  2.2 运维支持（日常巡检/状态监测/年度评估）
  2.3 服务承诺（SLA：响应时间/解决时间/可用率/备件供应）
```

## 三、核工业项目技术标编写 Checklist

1. 【资质】HAF601/602/603/安全生产许可/辐射安全许可是否齐备且范围覆盖？
2. 【适配表】是否单独编制核安全许可适配性说明表并标注页码索引？
3. 【双证时效】双证有效期是否覆盖开工至商运后首年全部节点？
4. 【业绩三同】业绩是否满足同堆型/同阶段/同角色，且附质保等级？
5. 【质保大纲】是否按 HAF003 十三要素编写质保大纲并引用具体条款？
6. 【专用条款】核岛专用参数是否逐条响应，无通用条款替代？
7. 【辐射防护】辐射分区/屏蔽/剂量监测/废物管理方案是否完整？
8. 【人员资质】注册核安全工程师/核级焊工/无损检测Ⅲ级人员证书+社保？
9. 【限价】报价是否低于最高投标限价？
10. 【形式】骑缝章/密封/签字盖章/正副本是否合规？
