## 背景

采用混合方案：不敏感知识库放 ima 云端，敏感知识库后续建本地。
ima-mcp API 不支持创建新知识库，需在 ima 客户端手动创建，创建后通过 MCP 入库内容。

### 创建步骤（ima.copilot PC 端）

1. 打开 ima.copilot 客户端
2. 点击左侧「知识库」标签
3. 点击「+ 新建知识库」
4. 选择「共享知识库」
5. 输入知识库名称和描述
6. 点击创建
7. 重复以上步骤创建 5 个知识库

### 创建步骤（ima.qq.com 网页端）

1. 访问 https://ima.qq.com 并登录
2. 进入「知识库」页面
3. 点击「新建知识库」
4. 选择类型为「共享知识库」
5. 填写名称和描述
6. 创建完成后，知识库会出现在列表中

## 第二步：获取知识库 ID

创建完成后，告诉我知识库的名称。我会通过 ima-mcp 的 `get_knowledge_base_list` 接口查询到新创建的知识库 ID。

或者你也可以在 ima 客户端中查看知识库详情，通常 URL 中会包含知识库 ID。

---

## 第三步：入库种子内容

获取到知识库 ID 后，我会通过以下流程将种子内容入库：

```
1. create_media（创建上传凭证）
   → 传入知识库ID + 文件名 + 文件大小 + MIME类型(text/markdown)
   → 返回 media_id + COS上传凭证

2. 上传文件到 COS
   → 用返回的凭证将 Markdown 文件上传到腾讯云

3. add_knowledge（入库）
   → 传入知识库ID + media_id
   → 文件进入知识库，ima 自动解析并建立索引
```

入库后，招标解析专家就可以通过 `search_knowledge` 或 `search_knowledge_base` 检索法规条文和废标模式。
