# 设备采购标书知识库（种子版 v1.0）

> 本知识库面向机械设备、电气设备、信息化设备、实验室仪器、安防监控、教学实训设备等**设备采购类项目**的投标工作。
> 供招标解析专家识别设备类资格要求/技术标准/评分要求，供技术方案架构师和编写专家检索引用。
> 每条知识标注：适用场景、核心要求、标书响应要点、常见废标风险。

---

## 一、设备采购项目概览

### 1.1 设备采购的定义与范围

设备采购指以政府采购、工程货物招标或企业采购方式，对**有形设备**进行采购的活动，区别于纯软件（服务）采购和工程施工。常见品类：

| 品类 | 典型标的 | 常见采购人 |
|------|---------|-----------|
| 通用办公设备 | 台式机、笔记本、打印机、复印机、空调 | 机关事业单位 |
| 信息化设备 | 服务器、存储、网络设备、监控安防、大屏 | 政务/企业/学校 |
| 教学实训设备 | 实训室设备、实验室仪器、机器人、自动化产线 | 高校/职校 |
| 医疗设备 | 医学影像、检验仪器、康复设备 | 医院 |
| 机械设备 | 机床、电梯、生产线、特种车辆 | 工厂/工程 |
| 专用设备 | 实验室家具、危化品存储柜、防爆设备 | 科研/化工 |

**适用场景**：招标解析时判断项目属性（设备 vs 软件 vs 工程）；技术方案编写时选择对应技术框架。

### 1.2 设备采购项目属性判断

- 依据《政府采购品目分类目录》确定项目属性（A类货物），无法确定时按"有利于采购项目实施的原则"确定。
- 设备+安装集成混合项目：以**核心产品**判断属性——非单一产品采购项目，采购人应确定核心产品并在招标文件中载明（87号令第31条）。
- 设备采购多采用**公开招标**；技术简单、规格统一的设备可选用**经评审的最低投标价法**；技术复杂的选用**综合评分法**。

**标书响应要点**：投标前先明确本项目是"设备采购"还是"设备+服务（集成）"，确定核心产品，避免响应错位。

## 二、设备采购核心法规

### 2.1 政府采购货物和服务招标投标管理办法（财政部令第87号）

**适用场景**：政府采购类设备采购项目（公开招标/邀请招标）全流程。

| 条款 | 核心要求 | 标书响应要点 |
|------|---------|-------------|
| 第11条 | 采购需求应完整明确：功能目标、执行标准、质量安全、技术规格、数量交付、服务标准、验收标准 | 投标文件应逐条响应采购需求，尤其是"验收标准"和"技术规格" |
| 第17条 | 不得将注册资本/资产总额/营业收入/从业人员/利润/纳税额等**规模条件**作为资格要求或评审因素 | 检查招标文件是否存在歧视性规模条款，可质疑 |
| 第20条 | 招标文件应载明：投标邀请、投标人须知、资格资信证明、政采政策要求、报价与保证金、技术规格数量服务验收、合同文本、评标方法标准、投标无效情形等15项 | 逐项核对投标文件要素是否齐全 |
| 第22条 | 一般不得要求提供样品，仅凭书面方式不能准确描述需求或需主观判断时除外 | 需提供样品时须明确样品制作标准、检测报告要求、评审方法 |
| 第31条 | **相同品牌处理规则**：最低评标价法只取报价最低的1家参评；综合评分法同品牌按1家计算 | 代理品牌时注意同品牌竞争被合并计算的风险 |
| 第32条 | 投标文件应对招标文件要求作出**明确响应** | 技术偏离表逐条响应，不得遗漏 |
| 第37条 | 串通投标6种情形认定 | 避免投标文件异常一致、报价规律性差异、保证金同账户等 |
| 第49条 | 评标委员会有权要求投标人对含义不明确的内容书面澄清，但**不得改变投标文件的实质性内容** | 开标后补正受限，投标前必须自检 |

**常见废标风险**：不满足实质性条款（★/▲/加粗条款）、同品牌竞争被合并、未按格式填写偏离表。

### 2.2 招标投标法及实施条例（设备类适用条款）

- 招标投标法第18条：不得以不合理条件限制排斥潜在投标人、不得歧视。
- 招标投标法第20条：**招标文件不得要求或标明特定生产供应者**（禁止指定品牌/型号）。
- 实施条例第32条：技术参数不得指向特定专利、商标、名称、设计、原产地。
- 实施条例第33条：投标人参加依法必须招标项目投标，不受地区或部门限制。

**常见废标风险**：招标文件指定品牌（可质疑）、投标文件涉及指定品牌响应过度（保持技术参数响应即可，不绑定单一品牌）。

### 2.3 政府采购法第22条 — 供应商资格通用条件

> ①具有独立承担民事责任的能力；②具有良好的商业信誉和健全的财务会计制度；③具有履行合同所必需的设备和专业技术能力；④有依法缴纳税收和社会保障资金的良好记录；⑤参加政府采购活动前三年内，在经营活动中没有重大违法记录；⑥法律、行政法规规定的其他条件。

**标书响应要点**：资格证明材料必须逐项对应——营业执照、财务审计报告、纳税证明、社保缴纳证明、无重大违法记录声明（信用中国/政府采购网查询）。

## 三、设备采购投标文件结构与编写要点

### 3.1 标准设备投标文件结构（参考国家标准设备采购招标文件2017版/各地示范文本）

```
第一部分 商务部分
├── 投标函
├── 法定代表人（单位负责人）身份证明 / 授权委托书
├── 联合体协议书（如适用）
├── 投标保证金（保函/转账凭证）
├── 资格审查资料（基本情况表/财务状况/类似业绩/诉讼仲裁/制造商授权书/信誉声明）
├── 商务条款偏离表
├── 中小企业声明函（如适用）
第二部分 报价部分
├── 开标一览表（总价）
├── 分项报价表（每台设备单价/数量/合价）
├── 备品备件/易损件报价表（如要求）
└── 质保期满后维保费用报价表（如要求）
第三部分 技术部分
├── 设备技术性能指标的详细描述（逐条响应技术规格）
├── 技术规格偏离表（正偏离/负偏离标注）
├── 技术支持资料（检测报告/认证证书/制造商印刷资料）
├── 技术服务和质保期服务计划（安装调试/培训/运维）
└── 供货方案（生产计划/物流/到货计划/项目进度）
```

### 3.2 设备类投标文件编写要点

| 章节 | 编写要点 | 常见失分点 |
|------|---------|-----------|
| 投标函 | 响应招标编号、项目名称、报价金额（大小写一致）、有效期 | 有效期不足招标文件要求、报价大小写不一致 |
| 分项报价表 | 与开标一览表汇总一致；数量×单价=合价；含税/不含税标注 | 汇总计算错误、漏报备件、报价格式不符 |
| 技术偏离表 | **逐条响应**招标技术参数；正偏离需提供证明材料支撑 | 负偏离或未响应累计超限→废标（详见4.2） |
| 技术规格描述 | 用表格+参数对照呈现；对★/▲条款逐条应答并附证明 | 仅写"完全响应"不提供证明材料 |
| 制造商授权书 | 代理投标时须提供原厂针对**本项目**的授权原件 | 授权过期/非本项目/缺公章 |
| 供货方案 | 明确生产周期、发货、到货、安装调试、验收时间表 | 与招标交货期冲突 |

## 四、设备采购评标方法与废标风险

### 4.1 常用评标方法

**（1）综合评分法（设备类常用）**

| 评分项 | 常见分值区间 | 评分要点 |
|--------|-------------|---------|
| 价格分 | 30-50分 | 低价优先法或平均价法；报价超出最高限价=无效 |
| 技术分 | 25-45分 | 参数响应、检测报告、样品/演示、技术方案 |
| 商务分 | 10-25分 | 业绩、售后服务（响应时间/质保期/备件）、团队、认证 |
| 政策分 | 0-5分 | 节能环保产品、中小企业、残疾人福利性单位 |

**（2）经评审的最低投标价法（技术简单、规格统一的设备）**
- 评标价=投标报价+技术/商务偏离修正价；投标报价评分分值一般不应少于40分。

### 4.2 设备采购核心废标规则

1. **实质性条款不满足或负偏离** → 投标文件无效（★/▲/加粗条款为实质性要求）。
2. **负偏离/未响应条款累计超限** → 视为未实质性响应（常见规则：单个产品项下累计超3项，或全部产品累计超25项）。
3. **技术参数响应证明材料缺失/模糊** → 无法证明参数符合要求，视为未响应实质性要求。
4. **技术偏离表未按给定格式填写、未按规定签章** → 符合性审查不通过。
5. **同品牌产品多投标人** → 按1家计算，非最优报价的同品牌投标无效（综合评分法）/报价最低外的同品牌投标无效（最低评标价法）。
6. **未提供制造商授权/授权无效**（要求授权的设备）→ 资格性审查不通过。
7. **样品不达标**（要求样品的项目）→ 技术评审不通过。
8. **投标设备不满足"在采购地可合法上牌/使用"等合规要求** → 实质性条款不满足，投标无效。

## 五、设备采购履约与验收要点

| 阶段 | 关键动作 | 依据 |
|------|---------|------|
| 到货验收 | 双方核对品牌/型号/规格/数量/外观/随机资料（合格证、保修卡、说明书、原厂证明），签署《到货验收单》 | 87号令履约验收规定 |
| 开箱检验 | 依据装箱单与合同清单核对附件、工具 | 标准设备采购合同条款 |
| 安装调试 | 按国家标准安装验收规范（如GB 50231）组织；隐蔽工程留存影像资料 | 安装验收规范 |
| 功能验收 | 逐项测试设备功能/性能指标，可邀请其他投标人或第三方参与 | 87号令第74条 |
| 质保服务 | 质保期内响应时限（常见：24小时响应、72小时上门）、备件保障 | 招标文件质保条款 |

**标书响应要点**：投标文件中应承诺到货/安装/调试/验收时间节点、质保期（常见3年）、响应时限、培训方案，并写明与招标文件验收标准的对应关系。

## 六、设备采购专项政策

### 6.1 进口产品政策

- 政府采购应当采购**本国货物**；确需采购进口产品的，须报财政部门审核同意。
- 招标文件不得将"进口产品"作为资格要求；已获准进口的项目，招标文件应载明。

### 6.2 节能环保政策

- 落实节约能源、保护环境政策；节能产品/环境标志产品优先或强制采购（列入品目清单的）。
- **标书响应要点**：投标产品具备节能/环保认证的，在投标文件中提供认证证书复印件，争取政策加分。

### 6.3 中小企业扶持

- 对小型和微型企业产品的价格给予扣除（常见6%-10%），用扣除后的价格参与评审。
- **标书响应要点**：符合条件的提供《中小企业声明函》及证明材料；声明函格式必须按招标文件附件格式填写。

## 八、设备采购领域拓展（待补充）

> 以下细分领域内容可作为后续种子文件扩充方向（管理员统一维护）：

1. **医疗设备采购**：医疗器械注册证（NMPA）、大型医用设备配置许可、招标文件对注册证的实质性要求。
2. **教育/教学设备**：实验室仪器、实训基地设备的技术标准与验收规范。
3. **特种车辆**：车辆公告目录、上牌合规、改装备案要求。
4. **新能源/节能设备**：能效等级、绿建标准、补贴政策。
5. **信创设备**：安全可靠测评、信创目录产品要求（通用服务器政府采购需求标准2023年版等）。
