## 一、GBZ 117-2022《工业探伤放射防护标准》

### 标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | GBZ 117-2022 |
| 标准名称 | 工业探伤放射防护标准 |
| 替代标准 | GBZ 117-2015、GBZ 132-2008、GBZ 175-2006 |
| 发布机构 | 国家卫生健康委员会 |
| 发布日期 | 2022-10-13 |
| 实施日期 | 2023-03-01 |
| 标准性质 | 国家强制性卫生标准（GBZ） |

### 适用范围

本标准规定了使用 X 射线和 γ 射线进行工业探伤的放射防护要求，适用于：
- 核设施建造、维修、退役各阶段的探伤作业
- 压力容器、管道、焊缝的无损检测
- 核电主设备、辅机、配件制造过程中的射线检验
- 核燃料元件、包壳、组件的完整性检验

### 核心要求

#### 使用单位放射防护要求

1. **成立放射防护组织**：建立放射防护管理机构或指定专职/兼职防护人员
2. **制定防护规章制度**：操作规程、定期检查、应急预案
3. **人员健康管理**：岗前体检、在岗期间定期体检、个人剂量监测档案（保留 ≥ 30 年）
4. **工作场所分区**：控制区、监督区明确划分，控制区入口设置警示标志

#### 探伤机的放射防护要求

1. **设备固有安全设计**：
   - 曝光时锁定装置
   - 紧急停机装置
   - 安全联锁装置
   - 警示信号装置

2. **照射量控制**：
   - 周围剂量当量率限值：公众 ≤ 0.1 μSv/h，工作人员操作位 ≤ 5 μSv/h
   - 屏蔽计算：依据源活度、距离、照射时间、TBI 计算

3. **场所防护**：
   - 固定探伤室：屏蔽墙、防护门、警示灯、门机联锁
   - 移动探伤：临时屏蔽、警戒范围（一般 ≥ 40m）

### 标书响应要点

技术方案涉及工业探伤（含 X 射线、γ 射线、电子加速器）需说明：

| 维度 | 响应内容 |
|------|---------|
| **法规符合性** | 引用 GBZ 117-2022，明确"自 2023-03-01 起执行新标准" |
| **防护设计** | 屏蔽计算（TBI 法）、分区设计、控制区警示 |
| **设备配置** | 探伤机选型（含安全联锁）、固定场所屏蔽工程 |
| **人员保障** | 放射工作人员证、个人剂量计、健康档案制度 |
| **监测与应急** | 工作场所剂量监测方案、应急响应预案 |
| **退役方案** | 探伤源退役流程（含废源处置、监管申报） |

### 标书响应模板

```
本项目涉及工业探伤（含 X 射线、γ 射线）作业，严格执行 GBZ 117-2022《工业探伤放射防护标准》：

1. 成立项目放射防护管理小组，设专职防护负责人 1 名。
2. 作业人员全部持《放射工作人员证》上岗，建立个人剂量档案与健康档案。
3. 固定探伤室采用混凝土+铅板复合屏蔽，剂量率实测满足 GBZ 117-2022 控制限值。
4. 移动探伤作业设置 ≥40m 警戒范围，专人监护，配备环境剂量监测仪。
5. 探伤源退役由具有相应资质单位承担，按程序向监管部门申报。
```
