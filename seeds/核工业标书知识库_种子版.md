# 核工业标书知识库（种子版 v1.0）

> 本知识库面向核工程、核设施、放射防护、核级设备与核安全相关信息化项目的投标工作。
> 供招标解析专家识别核工业特殊资质/技术/合规要求，供技术方案架构师和商务标书专家检索引用。
> 每条知识标注：适用场景、核心要求、标书响应要点、常见废标风险。

---

## 一、核安全法律法规框架

### 1.1 《中华人民共和国核安全法》（2018年1月施行）

| 条文 | 核心内容 | 标书响应要点 |
|------|---------|-------------|
| 第9条 | 核设施营运单位对核安全负全面责任 | 明确责任主体、质量责任制、可追溯管理 |
| 第17条 | 核设施选址、设计、建造、运行、退役实行许可制度 | 资质证书需覆盖核设施相关活动范围 |
| 第45条 | 核安全设备设计、制造、安装和无损检验单位须经国务院核安全监管部门许可 | 投标核安全设备项目必须持有 HAF601/602/603 许可证 |
| 第72条 | 核设施营运单位应建立核安全经验反馈体系 | 技术方案需含经验反馈机制、FAA 数据库对接 |

### 1.2 《民用核安全设备监督管理条例》（HAF601/602/603）

| 许可证 | 许可范围 | 投标场景 |
|--------|---------|---------|
| HAF601 | 民用核安全设备设计许可证 | 核级设备/仪控系统设计 |
| HAF602 | 民用核安全设备制造许可证 | 核级设备/部件制造 |
| HAF603 | 民用核安全设备安装许可证 | 核级设备安装、改造 |
| 无损检验许可 | UT/RT/PT/MT/ET/LT/VT 等核级无损检验 | 核级无损检验服务 |

**标书响应要点**：
- 必须在资质章节清晰列出许可证编号、许可范围、有效期
- 许可范围必须与招标内容严格对应（设备类别、核安全级别）
- 联合体投标时，各方许可范围叠加覆盖招标内容

### 1.3 核安全导则（HAD 系列）

| 编号 | 名称 | 适用场景 |
|------|------|---------|
| HAD102/03 | 核电厂在役检查 | 在役检查项目 |
| HAD102/07 | 核电厂设计中的辐射防护 | 核设施设计项目 |
| HAD102/14 | 核电厂安全有关仪表和控制系统 | 核级仪控项目 |
| HAD102/16 | 核电厂基于计算机的安全重要系统软件 | 核级软件/数字化仪控项目 |
| HAD003/01~10 | 核电厂质量保证安全规定 | 所有核工程项目的质保大纲 |

## 二、放射防护标准

### 2.1 GBZ 117-2022《工业探伤放射防护标准》

**适用场景**：核工业无损检测、工业射线探伤、放射源/射线装置应用项目投标。

| 维度 | 核心要求 | 标书响应要点 |
|------|---------|-------------|
| 放射源管理 | 放射源购买、运输、贮存、使用、报废全流程许可 | 列明辐射安全许可证、放射源编码、台账管理 |
| 分区管理 | 控制区、监督区划分，剂量率限值 | 给出分区示意图、剂量率计算、边界距离 |
| 人员防护 | 个人剂量监测、职业健康检查、培训考核 | 剂量计佩戴方案、个人剂量档案、培训记录 |
| 监测与应急 | 辐射监测计划、辐射事故应急预案 | 监测设备清单、应急演练记录、报告流程 |
| 三废处理 | 放射性废物分类收集、暂存、处置 | 废物最小化措施、暂存设施、转运联单 |

**常见废标风险**：
- 未提供有效的《辐射安全许可证》
- 放射工作人员未持有辐射安全与防护培训合格证书
- 未明确个人剂量监测方案

### 2.2 GB 18871-2002《电离辐射防护与辐射源安全基本标准》

| 核心要求 | 标书响应要点 |
|---------|-------------|
| 剂量限值：职业人员 20mSv/年，公众 1mSv/年 | 给出剂量评估和优化措施 |
| 辐射防护三原则：实践正当性、防护最优化、个人剂量限值 | 方案中体现 ALARA 原则 |
| 辐射工作场所分级 | 明确甲、乙、丙级非密封源工作场所分级 |

## 三、核级软件与数字化仪控标准

### 3.1 HAD102/16《核电厂基于计算机的安全重要系统软件》

**适用场景**：核级 DCS、安全仪控系统、反应堆保护系统、数字化改造项目。

| 生命周期阶段 | 标书响应要点 |
|-------------|-------------|
| 需求分析 | 核安全功能需求追溯矩阵、SRS 规格说明 |
| 设计 | 架构设计、 defensive programming、失效安全设计 |
| 实现 | 编码规范、配置管理、版本控制 |
| 验证与确认（V&V） | 独立 V&V 计划、测试覆盖、动态/静态分析 |
| 鉴定 | 设备鉴定（EMC、抗震、温湿度、老化） |
| 变更管理 | 配置变更控制、影响分析、再验证 |

### 3.2 IEC 61508 / IEC 61511（功能安全）

| 安全完整性等级 | 适用场景 | 标书响应要点 |
|----------------|---------|-------------|
| SIL 1~4 | 安全仪控系统 | 给出 SIL 定级报告、安全生命周期计划 |
| HFT（硬件故障裕度） | 冗余架构设计 | 1oo2、2oo3 投票逻辑说明 |
| SFF（安全失效分数） | 可靠性计算 | 给出可靠性框图和 PFH/PFD 计算 |

### 3.3 IEEE 7-4.3.2 / IEC 60987 / IEC 62138

| 标准 | 适用场景 |
|------|---------|
| IEEE 7-4.3.2 | 核电厂安全系统数字计算机 | 
| IEC 60987 | 核电厂安全重要仪控系统 | 
| IEC 62138 | 核电厂安全重要仪控系统 计算机系统 |

## 四、核工业资质等效替代规则

### 4.1 核安全设备资质

| 原资质要求 | 可等效资质 | 替代条件 | 说明 |
|-----------|-----------|---------|------|
| HAF601 设计许可 | 持有 HAF602 制造许可且具备设计能力 | 需在设计分包或联合体协议中明确 | 谨慎使用，需招标方认可 |
| HAF603 安装许可 | 持有 HAF601/602 许可 + 特种设备安装资质 | 联合体方式覆盖 | 不能直接替代 |
| 核级无损检验资质 | 特种设备无损检测资质 + 核工业培训证明 | 仅限非安全级项目 | 核安全级不可替代 |

### 4.2 人员资质等效

| 原证书要求 | 等效证书 | 替代条件 |
|-----------|---------|---------|
| 注册核安全工程师 | 核工程相关专业高级技术职称 + 5年核行业经验 | 仅限管理/咨询类岗位，核安全关键岗不可替代 |
| 核级无损检验人员资格证书 | 特种设备无损检测 II 级 + 核工业专项培训 | 需项目经验证明 |
| 辐射安全与防护培训合格证书 | 省级生态环境部门培训合格证 | 有效期内 |

## 五、核工业废标条款模式（补充）

### DQ-N01：核安全许可证缺失废标

- **触发关键词**：HAF601、HAF602、HAF603、民用核安全设备设计许可证、制造许可证、安装许可证
- **表述模式**："投标人须持有有效的民用核安全设备 [设计/制造/安装] 许可证，许可范围须覆盖本项目"
- **法律依据**：《民用核安全设备监督管理条例》第7条
- **严重等级**：fatal
- **响应要点**：许可证编号、有效期、许可设备类别、核安全级别必须与招标要求逐条对应

### DQ-N02：注册核安全工程师不满足废标

- **触发关键词**：注册核安全工程师、核安全关键岗位、项目负责人
- **表述模式**："项目负责人须具备注册核安全工程师资格，且近3年有核设施项目经验"
- **严重等级**：fatal
- **响应要点**：证书编号、注册单位、项目经历、社保缴纳证明

### DQ-N03：辐射安全许可缺失废标

- **触发关键词**：辐射安全许可证、放射源、射线装置、无损检测
- **表述模式**："投标人须持有有效的辐射安全许可证，种类和范围须包含本项目使用的放射源/射线装置"
- **法律依据**：《放射性同位素与射线装置安全和防护条例》第5条
- **严重等级**：fatal

### DQ-N04：核质保大纲未建立废标

- **触发关键词**：质量保证大纲、HAD003、核安全质保
- **表述模式**："投标人须建立并实施覆盖本项目的核质量保证大纲，且经买方认可"
- **严重等级**：fatal
- **响应要点**：提交质保大纲程序清单、组织机构图、监查计划

### DQ-N05：核级设备业绩不满足废标

- **触发关键词**：核级业绩、核设施供货业绩、在役检查业绩
- **表述模式**："投标人近5年须具有 [数量] 个核级 [设备/系统/服务] 供货/服务业绩"
- **严重等级**：fatal
- **响应要点**：合同复印件、验收证明、业主证明，需脱敏后使用

## 六、标书响应常用表述模板

### 6.1 资质章节

```
我公司持有有效的民用核安全设备设计许可证（编号：XXX），许可范围涵盖本项目涉及的 XXX 类设备，
核安全级别为 1E 级/安全级。许可证有效期至 XXXX 年 XX 月。
同时，公司持有辐射安全许可证（编号：XXX），种类和范围包含 XXX 放射源/射线装置的使用。
```

### 6.2 技术方案章节

```
本项目严格遵循《核安全法》、HAD003《核电厂质量保证安全规定》及 HAD102/16《核电厂基于计算机的安全重要系统软件》要求，
建立覆盖需求、设计、实现、验证、确认、运行、退役全生命周期的软件工程体系。
项目配置独立 V&V 团队，关键安全功能采用 2oo3 表决架构，满足 SIL2 安全完整性等级要求。
```

### 6.3 人员章节

```
本项目配备注册核安全工程师 X 名、核级无损检验人员 X 名、辐射安全管理人员 X 名。
所有放射工作人员均持有有效的辐射安全与防护培训合格证书，并建立个人剂量监测档案。
```
