# 投标文件通用框架与封面模板

> 本文件提供投标文件的标准目录结构、封面格式、编排原则，适用于工程类、货物类、服务类、信息化类项目投标。
> 来源：综合各省市公共资源交易中心、政府采购中心发布的投标文件格式要求整理。
> 整理日期：2026-08-12

---

## 二、封面模板

### 2.1 标准封面格式

```
┌─────────────────────────────────┐
│                                 │
│        [项目名称]               │
│                                 │
│        投标文件                 │
│                                 │
│     （正本/副本）               │
│                                 │
│  项目编号：[项目编号]           │
│  所投标段：[标段名称]           │
│                                 │
│  投标人：[投标人全称]（盖章）   │
│                                 │
│  法定代表人或其委托代理人：      │
│  （签字或盖章）                 │
│                                 │
│  日期：[年]年[月]月[日]日       │
│                                 │
└─────────────────────────────────┘
```

### 2.2 信息化项目封面格式

```
┌─────────────────────────────────┐
│                                 │
│   [项目名称]                    │
│                                 │
│   技术方案                      │
│                                 │
│  ────────────────              │
│                                 │
│  投标人：[公司全称]（盖章）    │
│  日期：[投标日期]               │
│                                 │
└─────────────────────────────────┘
```

### 2.3 封面填写规范

| 要素 | 规范要求 |
|------|---------|
| 项目名称 | 必须与招标文件中的项目名称**完全一致**，不得简写或改写 |
| 项目编号 | 必须与招标公告/招标文件中的编号完全一致 |
| 投标人名称 | 填写企业全称（与营业执照一致），加盖单位公章 |
| 法定代表人签字 | 手写签字或电子签章，不得用签名章代替 |
| 日期 | 填写实际投标截止日或之前的工作日 |
| 正本/副本 | 正本1份，副本数量按招标文件要求（通常2-4份） |
| 电子版 | U盘或光盘1份，与正本内容一致 |

## 三、目录与索引编制规范

### 3.1 目录编制要求

- **清晰分层**：使用多级编号（1.、1.1、1.1.1）体现章节层次
- **准确页码**：页码必须与实际内容完全一致，正本与副本页码统一
- **对齐排版**：页码右对齐，章节标题左对齐，使用前导符（......）连接
- **完整性**：所有主要章节、子章节都应包含在目录中
- **位置**：目录位于封面、授权书、投标函之后，正文内容之前

### 3.2 评分索引表模板

> 综合评分法项目必须编制评分索引表，帮助评标专家快速定位评分内容。

| 序号 | 评分因素 | 分值 | 评分标准 | 投标文件所在页码 |
|------|---------|------|---------|----------------|
| 1 | 技术方案 | [X] | [评分标准描述] | 第[X]-[X]页 |
| 2 | 项目团队 | [X] | [评分标准描述] | 第[X]-[X]页 |
| 3 | 业绩 | [X] | [评分标准描述] | 第[X]-[X]页 |
| 4 | 服务承诺 | [X] | [评分标准描述] | 第[X]-[X]页 |
| 5 | 报价 | [X] | [评分标准描述] | 第[X]-[X]页 |
| ... | ... | ... | ... | ... |
| 合计 | | 100 | | |

### 3.3 方案索引表模板

| 序号 | 招标文件条目号 | 招标文件服务要求 | 在投标文件中的页码 | 在对应方案中的段落 | 备注 |

## 四、投标文件编排与装订规范

### 4.1 格式规范

| 项目 | 规范要求 |
|------|---------|
| 纸张 | A4白纸（210mm×297mm），双面打印或单面打印（按招标文件要求） |
| 字体 | 正文宋体/仿宋小四号，标题黑体三号，表格宋体五号 |
| 行距 | 1.5倍行距或固定值28磅 |
| 页边距 | 上2.5cm，下2.5cm，左2.5cm（装订侧），右2cm |
| 页码 | 底部居中，格式"第X页共Y页" |
| 装订 | 胶装或线装，不得使用活页夹；正本和副本分别装订 |
| 密封 | 独立密封袋包装，封口处加盖公章 |

### 4.2 正本与副本

| 区别 | 正本 | 副本 |
|------|------|------|
| 签字盖章 | 法定代表人/授权代表亲笔签字 + 公章 | 可用正本复印件 |
| 标注 | 封面注明"正本" | 封面注明"副本" |
| 优先级 | 正副本不一致时，以正本为准 | |
| 数量 | 1份 | 按招标文件要求（通常2-4份） |

### 4.3 电子版要求

- 格式：PDF（只读，不可编辑）
- 与正本内容完全一致
- U盘或光盘介质，贴标签注明项目名称、编号、投标人
- 与纸质文件一同密封递交
