# 软件开发行业标准 — 2024-2025年标准更新

> 本文件收录2024-2025年新发布或更新的软件开发与政务信息化项目相关技术标准，作为"软件开发标书知识库"的补充更新。
> 适用于：政务信息化、企业数字化、软件定制开发、系统集成类项目的标书技术方案与安全方案撰写。
> 来源：全国网络安全标准化技术委员会（TC260/网安标委）、国家市场监督管理总局、国家标准化管理委员会。
> 检索日期：2026-08-12

---

## 一、数据安全国家标准体系（2025版）

**发布机构**: 全国网络安全标准化技术委员会秘书处
**发布日期**: 2025年9月

### 体系框架

数据安全国家标准体系由六大类标准组成：

| 类别 | 代号 | 核心内容 |
|------|------|---------|
| 基础共性 | A | 术语、数据安全参考架构、数据分类分级、数据安全保护 |
| 数据安全技术和产品 | B | 数据资源管理、全生命周期保护、流通安全、处理行为安全 |
| 数据安全管理 | C | 数据处理活动安全、数据出境安全、数据安全运营、组织和人员 |
| 数据安全服务 | D | 风险评估、能力评价、管理认证、服务机构、规划咨询 |
| 产品和服务数据安全 | E | 数据产品/服务安全、系统/组件安全、典型产品、网络平台 |
| 行业与应用数据安全 | F | 行业领域数据安全、技术应用数据安全 |

### 标书响应要点

- 截至2025年8月，已制定发布44项数据安全和个人信息保护国家标准
- 正在制修订2项强制性国家标准和16项推荐性国家标准
- 技术方案中应引用最新版本的标准编号

## 二、GB/T 45396-2025《数据安全技术 政务数据处理安全要求》

**发布日期**: 2025年（国家市场监督管理总局、国家标准化管理委员会批准发布）
**实施日期**: 2025年10月1日
**牵头编制**: 国家信息中心

### 核心要求

首次聚焦政务数据收集、存储、使用、加工、传输、提供、公开及销毁全流程，面向数据安全管理、数据处理活动、数据安全技术和个人信息保护，系统化提出政务数据处理安全技术与管理要求。

### 指标体系

| 维度 | 指标数量 |
|------|---------|
| 一级指标 | 3项 |
| 二级指标 | 24项 |
| 三级指标 | 87项 |

### 三大维度

1. **安全制度规范** — 数据安全管理制度体系、流程规范
2. **安全技术防护** — 数据收集、存储、使用、加工、传输、提供、公开、销毁各环节技术要求
3. **安全运行管理** — 安全合规评估方法与评价指标体系

### 标书响应要点

- 政务信息化项目技术方案必须引用此标准
- 需在安全方案章节说明数据全生命周期安全防护措施
- 需承诺通过数据安全合规评估

## 三、GB/T 43697-2024《数据安全技术 数据分类分级规则》

**实施日期**: 2024年

### 核心要求

- 规定数据分类分级的规则和方法
- 给出重要数据识别的指南
- 数据分类：按行业领域、业务类别等维度分类
- 数据分级：一般数据、重要数据、核心数据三级

### 标书响应要点

| 数据级别 | 标书响应要求 |
|---------|-------------|
| 一般数据 | 基本安全防护措施（加密、访问控制） |
| 重要数据 | 增强安全防护（加密存储、异地备份、访问审计） |
| 核心数据 | 最高安全防护（物理隔离、专网传输、专人管理） |

## 四、GB/T 45577-2025《数据安全技术 数据安全风险评估方法》

**实施日期**: 2025年

### 核心要求

- 规定数据安全风险评估的方法和流程
- 评估维度：数据资产识别、威胁分析、脆弱性识别、风险计算
- 评估周期：至少每年一次，重大变更后及时评估

### 标书响应要点

- 技术方案需包含数据安全风险评估计划
- 需说明评估方法、评估周期、整改措施

---

## 五、GB/T 45574-2025《数据安全技术 敏感个人信息处理安全要求》

**实施日期**: 2025年

### 核心要求

- 敏感个人信息定义：身份证号、护照号、银行卡号、健康信息、行踪轨迹、人脸信息等
- 处理原则：最小化采集、明示同意、目的限制
- 技术要求：加密存储、脱敏展示、访问审计、去标识化处理

### 标书响应要点

| 处理环节 | 安全要求 | 标书方案 |
|---------|---------|---------|
| 采集 | 最小化原则、明示告知 | 采集清单、隐私政策 |
| 存储 | 加密存储、访问控制 | AES-256加密、RBAC权限 |
| 传输 | 加密传输 | TLS 1.3、VPN |
| 使用 | 脱敏展示、审计日志 | 动态脱敏、操作审计 |
| 删除 | 不可恢复删除 | 安全擦除、销毁记录 |

## 六、《网络数据安全管理条例》（国务院令第790号）

**发布机关**: 国务院
**性质**: 行政法规

### 与标书相关的核心要求

| 条款 | 核心内容 | 标书响应要点 |
|------|---------|-------------|
| 第9条 | 网络数据处理者应在等保基础上加强数据安全防护 | 技术方案引用等保+数据安全双重要求 |
| 重要数据处理 | 需开展风险评估并上报 | 包含风险评估方案 |
| 数据出境 | 依法进行安全评估 | 涉及出境数据需通过安全评估 |

## 八、信创（信息技术应用创新）标准要求

### 国产化替代趋势

- 2024-2025年政务信息化项目普遍要求信创兼容
- 标书需说明：国产CPU（龙芯/飞腾/鲲鹏）、国产OS（统信/麒麟）、国产数据库（达梦/人大金仓/华为GaussDB）、国产中间件（东方通/中创）的适配方案
- 信创测试报告可作为加分项

### 标书响应模板

```
本项目全面支持信创环境部署，具体适配方案如下：
- CPU: 龙芯5000系列 / 飞腾2500 / 鲲鹏920
- 操作系统: 统信UOS V20 / 麒麟V10
- 数据库: 达梦V8 / 人大金仓KingbaseES V8
- 中间件: 东方通TongWeb / 中创InforSuite AS
- 浏览器: 奇安信可信浏览器 / UOS浏览器
- 已取得信创测试报告，编号: [信创测试报告编号]
```
