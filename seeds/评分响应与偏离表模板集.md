# 评分响应与偏离表模板集

> 本文件提供综合评分法项目中常用的响应表和偏离表标准模板。
> 来源：综合南京财经大学、江苏省环境监测中心、重庆医药高等专科学校等招标文件格式整理。
> 整理日期：2026-08-12

---

## 一、技术参数响应及偏离表

> 用途：对照招标文件技术规格，逐条说明投标响应情况。

**技术参数响应偏离表**

项目名称：[项目名称]
招标编号：[编号]
投标人名称：[投标人全称]（盖章）

| 序号 | 货物名称/服务名称 | 招标文件技术参数规格及要求 | 投标文件技术参数规格及响应 | 响应情况 | 说明 |
|------|-------------------|------------------------|------------------------|---------|------|
| 1 | [名称] | [招标参数要求] | [投标参数] | 响应/正偏离/负偏离 | [说明] |
| 2 | [名称] | [招标参数要求] | [投标参数] | 响应/正偏离/负偏离 | [说明] |
| 3 | [名称] | [招标参数要求] | [投标参数] | 响应/正偏离/负偏离 | [说明] |
| ... | ... | ... | ... | ... | ... |

> **填写说明**：
> 1. 偏离符号："+"表示正偏离（优于），"="表示完全响应，"-"表示负偏离（低于）
> 2. 投标人必须对照招标文件技术规格，逐条说明已做出的实质性响应
> 3. 特别对有具体参数要求的指标，必须提供具体参数值，不得以"全部符合"等字样响应
> 4. 评委会如发现有虚假描述的，该投标文件视为无效
> 5. 负偏离可能导致废标或扣分（视招标文件规定）

## 二、商务条款响应及偏离表

> 用途：对照招标文件商务条款（交货期、付款方式、质保期等），逐条说明响应情况。

**商务条款响应偏离表**

项目名称：[项目名称]
招标编号：[编号]
投标人名称：[投标人全称]（盖章）

| 序号 | 项目 | 招标文件商务要求 | 投标文件商务响应 | 响应情况 | 说明 |
|------|------|----------------|----------------|---------|------|
| 1 | 交货期/服务期 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 2 | 交货地点/服务地点 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 3 | 验收方式 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 4 | 付款方式 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 5 | 质保期/缺陷责任期 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 6 | 知识产权 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 7 | 售后服务 | [要求] | [响应] | 响应/正偏离/负偏离 | |
| 8 | 投标有效期 | [要求] | [响应] | 响应 | |
| 9 | 投标保证金 | [要求] | [响应] | 响应 | |
| 10 | 履约保证金 | [要求] | [响应] | 响应/正偏离 | |

> **填写说明**：
> 1. 投标人须对照招标文件中所有商务条款和相关服务要求，逐条响应
> 2. 投标单位根据项目添加的服务承诺、培训等也请列入此表
> 3. 是否偏离用符号"+/=/-"分别表示正偏离、完全响应、负偏离
> 4. 投标单位必须如实填写，评委会如发现有虚假描述的，该投标文件视为无效

## 三、"*"号条款逐条响应表

> 用途：招标文件中标注"*"号的关键条款（带星号条款），投标人必须逐条书面响应及承诺，
> 任何一条不响应即视为无效投标。

**"*"号条款逐条响应情况表**

投标人名称：[投标人全称]（盖章）
项目名称：[项目名称]

| 序号 | 招标文件要求"*"号条款 | 投标响应情况 | 投标响应内容所在页码 | 完全响应/非完全响应 |
|------|---------------------|------------|-------------------|-------------------|
| 1 | [条款1内容] | [响应描述] | 第[X]页 | 完全响应 |
| 2 | [条款2内容] | [响应描述] | 第[X]页 | 完全响应 |
| 3 | [条款3内容] | [响应描述] | 第[X]页 | 完全响应 |
| ... | ... | ... | ... | ... |

> **重要提醒**：
> - 以上*号条款为招标文件中的所有*号条款
> - 无论是技术指标或文字描述要求，投标人必须逐条书面响应及承诺
> - 任何一条*号条款非完全响应，将导致投标无效

## 七、承诺函模板

### 7.1 投标及履约承诺函

```
投标及履约承诺函

致：[采购人名称]

我单位承诺：
1. 我单位参与本项目所投标（响应）的货物、工程或服务，
   不存在侵犯知识产权的情况。

2. 我单位参与本项目政府采购活动前三年内，
   在经营活动中没有重大违法记录。

3. 我单位具备《中华人民共和国政府采购法》第二十二条第一款
   规定的六项条件。

4. 我单位未被列入失信被执行人、重大税收违法案件当事人名单、
   政府采购严重违法失信行为记录名单，
   否则取消其参选资格，并承担由此造成的一切法律责任及后果。

5. 我单位参与该项目投标，严格遵守政府采购相关法律，
   不造假，不围标、串标、陪标。
   我单位已清楚，如违反上述要求，
   投标将作无效处理，被列入不良记录名单并在网上曝光，
   同时将被提请政府采购主管部门给予一定年限内禁止参与
   政府采购活动或其他处罚。

投标人：[盖单位公章]
法定代表人或授权代表：[签字]
日期：[年]年[月]月[日]日
```
