# 行业技术标准库（种子版 v1.0）

本知识库供技术方案架构师、技术标书编写专家、技术方案审核专家检索引用，覆盖信息化项目常见技术标准要求。每条标准标注：标准编号、适用场景、核心要求、标书响应要点。

## 一、网络安全等级保护标准（等保2.0）

### GB/T 22239-2019 网络安全等级保护基本要求

**适用场景**: 政务、金融、医疗、教育等信息化项目安全设计

#### 等保二级核心要求

| 安全域 | 核心要求 | 标书响应要点 |
|--------|---------|-------------|
| 物理安全 | 机房物理访问控制、防火/防水/防雷 | 说明机房等级（T3+/T4），列明物理安全措施 |
| 网络安全 | 边界防护、访问控制、入侵防范 | 部署防火墙/IPS，网络区域隔离方案 |
| 主机安全 | 身份鉴别、访问控制、安全审计、入侵防范 | 操作系统加固方案、主机审计日志保留≥6个月 |
| 应用安全 | 身份鉴别、访问控制、通信完整性 | 多因素认证、RBAC权限模型、HTTPS加密传输 |
| 数据安全 | 数据完整性、数据保密性、数据备份恢复 | 数据加密存储、异地备份策略、恢复时间目标(RTO)≤4h |

#### 等保三级附加要求

| 安全域 | 附加要求 | 标书响应要点 |
|--------|---------|-------------|
| 物理安全 | 防电磁泄露、电力冗余 | 双路供电、UPS+柴油发电机 |
| 网络安全 | 网络入侵检测、恶意代码检测 | 部署IDS/态势感知、流量分析 |
| 主机安全 | 恶意代码防范、资源控制 | 主机入侵检测、资源配额管理 |
| 应用安全 | 软件容错、资源控制 | 应用级容灾、熔断限流机制 |
| 数据安全 | 数据隐私保护、备份异地存储 | 数据脱敏、异地灾备（同城+异地） |
| 安全管理 | 安全管理机构、人员管理、系统建设管理 | 设立安全主管、安全培训计划、SDL流程 |

#### 等保四级附加要求

- 所有三级要求基础上增强：双因子强认证、可信验证、隐蔽性保护
- 标书需说明：可信计算环境、强制访问控制(MAC)、安全域隔离

### GB/T 25058-2019 网络安全等级保护实施指南

**适用场景**: 制定等保实施方案

- 定级备案 → 总体安全规划 → 安全设计与实施 → 安全运行与维护 → 系统终止
- 标书需覆盖：定级依据、安全规划方案、实施步骤、运维安全制度

### GB/T 28448-2019 网络安全等级保护测评要求

**适用场景**: 技术方案审核专家评估安全方案完备性

- 测评指标：物理、网络、主机、应用、数据、管理6大类
- 测评结果：优(90+)、良(80+)、中(70+)、差(<70)
- 标书需注明：承诺通过等保测评等级、测评时间节点

| 测试计划/测试报告 | 测试阶段 | 质量保障方案 |

### GB/T 16260 系统与软件质量模型

| 质量特性 | 子特性 | 标书响应要点 |
|---------|--------|-------------|
| 功能性 | 完备性/正确性/适合性 | 功能清单100%覆盖需求 |
| 性能效率 | 时间特性/资源利用性/容量 | 响应时间≤2s，并发用户≥1000，数据容量设计 |
| 兼容性 | 共存性/互操作性 | 与现有系统对接方案、API兼容性 |
| 可靠性 | 成熟性/可用性/容错性 | 系统可用性≥99.9%，故障恢复≤30min |
| 安全性 | 保密性/完整性/抗抵赖性 | 等保要求响应 |
| 维护性 | 模块化/可复用性/易分析性 | 微服务架构、代码规范、技术文档交付 |
| 可移植性 | 适应性/易安装性/易替换性 | 容器化部署、多环境支持 |

### GB/T 30882 信息技术 应用系统集成标准

- 系统集成架构：数据集成/应用集成/界面集成/流程集成
- 标书需说明：集成方案（API/消息总线/数据交换平台）、集成标准（RESTful/SOAP/Kafka）

## 四、政务信息化专项标准

- 交换体系架构：交换平台 + 交换节点 + 交换标准

- 事项编码：部门代码 + 事项类型 + 顺序码
- 标书响应：政务事项管理系统设计、事项编码规范

- 国家政务大数据平台架构：国家-省-市三级
- 数据目录体系：政务数据资源目录 + 共享目录 + 开放目录
- 标书响应：数据目录管理方案、数据共享交换方案

## 七、工业探伤放射防护标准（自动索引 2026-08-10 17:20）

### GBZ117-2022 工业探伤放射防护标准
**替代标准**: GBZ 117—2015，GBZ 132—2008，GBZ 175—2006
**发布日期**: 2022-10-13  |  **实施日期**: 2023-03-01

**适用场景**: 本标准规定了 X射线和γ射线探伤的放射防护要求。

#### 核心要求

- 范围
- 规范性引用文件
- 术语和定义
- 使用单位放射防护要求
- 探伤机的放射防护要求

**标书响应要点**: 技术方案中需说明辐射防护设计、屏蔽计算、监测设备配置及人员防护方案

## 使用说明

1. 技术方案架构师在"安全合规设计"环节检索本库，确认技术方案满足对应等级的安全要求
2. 技术标书编写专家在编写"安全方案"章节时检索本库，引用具体标准编号和核心要求
3. 技术方案审核专家在"安全合规检查"环节检索本库，验证安全方案是否符合标准要求
4. 后续可持续扩展：行业专有标准（如金融行业等保实施细则、医疗信息化标准等）
